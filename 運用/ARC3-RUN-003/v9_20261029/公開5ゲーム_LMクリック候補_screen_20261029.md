# 公開5ゲーム: HDSクリック候補選択のpaired screen

## 判定

**REJECT — 性能改善としては採用しない。** Dは5条件すべてで行動を変えたが、ローカルSDK平均scoreがA/Bより低下した。level到達数と勝利数は変わらず、no-op減少は得点改善に結び付かなかった。

## 学習効果・限界

HDSの経験更新後、Dの選択はAと5/5で変わった。一方、score差は平均で悪化し、levelと勝利に差がない。よって「Actionが変わった」「no-opが減った」は観測できたが、学習による能力改善は実証できていない。得点はローカルSDK scorecardであり、公式Kaggle scoreと比較しない。ゲームごとにAgent/HDS状態を新規化しており、ゲーム間転移も未測定。

## 次の仮説

今回の行動overrideは`visible_change`だけを根拠にしていた。可視変化を得点報酬として使わず、探索時の情報価値として分離し、既存baselineが選んだACTION6内でのみHDSが点候補を順位づけする案を次に評価する。候補の正確なaction内訳を記録し、level進行・SDK scoreを合格条件にする。
