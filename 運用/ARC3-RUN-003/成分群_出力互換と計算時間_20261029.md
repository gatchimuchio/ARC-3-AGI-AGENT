# ARC3再設計 v3：連結成分の出力互換と計算時間

## 目的と変更

公開Frameの連結成分を探索候補に利用する前提として、`接続/図式観測.py` の `成分群` を高速化した。旧版は成分を一つ見つけるたびに残セル集合の最小値を再走査し、細かい成分が多い盤面で処理量が増える。新版は最初にセルを一度だけ同順序に並べ、処理済みセルを飛ばす。成分の色、点集合、正規化形、位置、出力順序は変えない。HDS・Agent・座標選択には接続していない。

## 同条件比較

比較元はmain commit `395c037866d912ef50d5be2bc573d926f4e24a98`。空盤面、不揃い行、単色、縞、64×64チェッカー、固定seedのランダム盤面を含む合成107条件で、旧版と新版の戻り値がすべて一致した。

| 指標 | 旧版 | 新版 |
| --- | ---: | ---: |
| 64×64チェッカー盤、3回の中央値 | 0.703558秒 | 0.039336秒 |
| 抽出成分数 | 4,096 | 4,096 |

上記の時間はWindows 11、Python 3.12.10で同じプロセス内に交互に測定した合成盤面の値。別の公開ゲーム評価と回帰試験が同時実行中で、単独負荷の保証や実ゲーム全体の速度を表さない。計算時間のみの改善であり、ゲーム得点・攻略能力・学習効果の改善は未測定。

## 次の検証
