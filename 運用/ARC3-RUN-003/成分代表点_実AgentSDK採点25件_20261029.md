# 成分代表点候補の実Agent・SDK採点：公開25ゲーム（2026-10-29）

## 結果

公開5ゲームの開発比較でlevel突破が増えた成分代表点候補を、同じ実Agent・bundle・入力版・seed・80要求予算で公開25ゲームへ拡張した。SDK scorecardを使用し、全25組の初期状態は一致、エラー・SDK／Agent警告・dispatchとstep／SDK操作数の不一致・HDS Action認可trueはいずれも0だった。

スコアは改善1組、悪化1組、同点23組。候補は新たな1 levelを突破した一方、別の1 levelでは突破を維持しながらSDK scoreが2.404433→1.587302へ低下し、前者の利益をわずかに上回る損失が生じた。行動列は19組で分岐した。GAME_OVER応答回数は独立ゲーム数ではない。最終frameが同じでも隠れた状態が不変とは限らない。

効率が低下した組は全7 level、両腕とも1 level完了、公開人間基準32操作、各1 playだった。SDKの重み付き得点式を逆算すると、完了までの操作数は基準39→候補48と推定される。**これは保存されたスコアと基準値からの推定**であり、今回の結果にlevel別操作数の生記録はない。原因となる操作を特定するには、公開遷移とSDKのlevel別記録を同条件で再取得する必要がある。

## 採否と次の作業

**レベル到達は増えたが、公開25ゲームの平均SDK scoreは改善していない。** 代表点候補を得点改善版として提出runtimeへ昇格しない。5ゲームでの利益だけで昇格すると、別ゲームの効率低下を見落とす結果だった。次は代表点の利用条件と進捗・効率の関係を、公開状態と遷移から一般的に説明できる仮説として検討する。ゲームID別の答え分岐や成功操作列の再生は行わない。

公開ゲームは過去に使用済みであり未見転移ではない。ローカルSDKのOFFLINE scoreはKaggle公式scoreではなく、過去の公式28.07と加減・直接比較できない。実行は基準→候補の順で他のローカル検証とも一部並行したため、経過時間を統制された性能比較として扱わない。
