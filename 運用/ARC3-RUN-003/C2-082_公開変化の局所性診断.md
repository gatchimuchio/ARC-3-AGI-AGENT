# C2-082 公開変化の局所性診断

## 得られた観測

C2-080と同じ検証済み239遷移を、学習器を呼ばず公開pixelだけで診断した。

- 実Action6の80件はすべて盤面全体が変化。しかし操作前target中心7×7の変化が0のものは26件、3×3で0のものは30件あった。
- 通常の盤面変化223件のうち28件は、変化が外周2画素だけに収まった。これは幾何学的な場所の記述であり、HUD・無効操作・失敗とは断定しない。
- 通常変化のpixel数は最小1・中央値34・最大224。進行4件は603・中央値2792.5・最大2972。再利用された4例から進行閾値を作ったり汎化を主張したりしない。

同色4連結componentを、色と正規化された同形状がbefore/afterに各1個だけある場合に限り対応させると、非zero変位は24遷移・33対応だった。しかし236遷移で同形状の曖昧さがあり、26,200 before-components中23,618が曖昧。物体同一性・生成消滅・因果を識別するものではなく、主候補に採用しない。

## 次の候補

候補は一つに限定し、**操作前target中心7×7内の変化と、その外側の変化を別々に観測する**。局所変化がないことを無反応や失敗へ変換せず、遠隔応答として残す。元のレベル進行・GAME_OVER等の公開応答は保持する。

次のC2-083では、既存の操作前特徴は変えず、この観測可能な応答をnativeが過去だけから学べるかを調べる。Action6以外へ欠落項目の0を発明せず新targetを省略する。prior-only Aと観測更新B、同じ対象stepの厳密な過去多数派を比較し、未予測の精度はUNKNOWNとして扱う。runtime採用・攻略得点改善は別の比較を要する。
