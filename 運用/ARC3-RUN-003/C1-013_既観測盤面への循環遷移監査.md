# ARC3-RUN-003 C1-013：既観測盤面へ戻る可視遷移の監査

## 選定根拠

- C1-011/012では盤面再訪が各seed34–45回あった一方、同一state-actionの選択文脈化はC2-038でlevel/WINを変えず、no-op減少も1 seedのみで棄却された。
- 現行報酬は、新規盤面なら`+0.5`を与えるが、盤面が変化しても既観測盤面へ戻る遷移には明示的な再訪罰がない。no-opとは別の循環遷移が複数回起きているかを変更なしで測る。

## 許可範囲

- `検証/`に隔離されたread-only evaluator・targeted testsだけを追加する。policy、agent、HDS、candidate、Notebook/kernelは変更しない。
- 固定dev split seed `20261022`、5公開環境、environment seeds `7/31/73`、各最大80 Action、GAME_OVER後RESET有効。
- `NOT_FINISHED`のAction応答で盤面が可視変化し、level進行せず、応答先盤面が同一run内で既観測だった回数を匿名集計する。レベル進行・terminal・no-opは循環遷移に含めない。
- 一時照合用の盤面と個票を出力しない。保存するのはseed別aggregateのみ。

## 次C2候補の事前条件

- 非終端の可視再訪遷移が各400 Action seed中10回以上、3 seeds中2以上で観測されたときだけ、循環回避rewardの単独ablationを別C2指示書で検討する。
- 条件未達なら循環罰を実装せずC1を閉じる。観測数だけで改善・公式score因果を主張しない。

## 完了証拠

- seed別の全可視非終端遷移、既観測盤面への遷移、割合、Action数、levels、no-op、GAME_OVER/RESET、illegal/duplicate/HOLDを保存する。
- source/input/test/output SHA256、禁止key監査、事前閾値採否を追記記録へ残す。
