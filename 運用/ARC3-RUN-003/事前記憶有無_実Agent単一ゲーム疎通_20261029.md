# 事前記憶あり／なしの実Agent疎通（2026-10-29）

## 対象と結果

事前記憶の非公開境界を保った代替構成の検討として、旧枝の実Agentを公開ゲーム1件で比較した。両腕は同じ代表点方針・seed・要求上限80・可視変化係数0.0・SDK採点を使い、Aは既存事前記憶loader、Bは事前記憶をHDSに投入しない5項目の報告を返す。両腕の初期公開観測は一致した。

| 指標 | A: 事前記憶あり | B: 未投入 |
|---|---:|---:|
| 事前記憶読込件数 | 5 | 0 |
| HDS更新／照会回数 | 78／80 | 78／80 |
| HDS優先による行動選択 | 0 | 0 |
| SDK採点／完了level | 0／0 | 0／0 |

両腕ともSDK・Agent警告0、SDK操作数とdispatchの不一致0、HDS Action認可false。行動列は一致した。この1ゲームでは事前記憶の有無による行動差や得点差は観測されなかった。

## 射程と次の検証

両腕とも同じ私的bundle内でloaderのみを切り替えており、Bから非公開ファイルを除去した公開可能bundleではない。1ゲームの疎通であって、事前記憶の無効性の一般的証明、学習効果、未見転移、Kaggle公式得点ではない。25ゲーム評価と並行したため実時間も比較しない。

公開可能な依存構成を作る場合は、非公開ファイルをbundle・Notebookから実際に除外し、manifestと動的importを検査した上で、この未投入条件と行動・SDK結果を照合する。事前記憶の有無に加え、代表点の有無も独立要因として同条件で比較する。
