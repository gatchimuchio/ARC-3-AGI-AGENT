# 権限順序

## 規範

1. Ownerの現在の明示指示
2. 最も近い`AGENTS.md`
3. この文書
4. `制御/現在状態.json`が選択する現行仕様・戦略・作業指示
5. 現行実装が持つinterface契約
6. 推測・記憶・一般論

## 現在状態

可変状態の入口は `制御/現在状態.json` だけとする。
README、AGENTS、Git履歴、旧artifactから現在状態を推定しない。

## 観測事実

規範と観測事実を分ける。

```text
どうあるべきか = 規範
何が成立しているか = 実行・検証・公式結果
```

両者が矛盾したら、矛盾そのものを不足として扱う。

## 履歴

今回の再初期化以前の資産はGit履歴に保存されるが、現行権威ではない。
Ownerが明示的に再利用を指示した場合だけ、候補資産として観測する。
