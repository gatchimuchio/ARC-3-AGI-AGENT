# ARC-AGI-3 専用仕様書 v6.0

対象リポ：[gatchimuchio/ARC-3-AGI-AGENT](https://github.com/gatchimuchio/ARC-3-AGI-AGENT)。共通仕様書と本書を一緒に使用。**ARC2の静的格子評価をARC3に転用しない。**

## 1. 本当の目的

**既存HDSラーニングマシンと構造化記憶で、初見ゲームを観測し、ルールを学び、行動して攻略する**。公開ゲームで進行・クリア・行動効率・学習前後を再現し、Kaggle**Competition Rerunの公式スコア**を上げ、100%と競技首位を狙う。

公式採点は各ゲームの各レベル攻略と人間基準に対する行動効率に基づく。Notebookの通常RUN COMPLETEや\`submission.parquet\`中の補助フィールドは**公式競技得点ではない**。Kaggle上の**Submit to Competition→Competition Rerun**を完了し、Leaderboard等の数値を対象版へ紐付ける。

公式：[Kaggle ARC3](https://www.kaggle.com/competitions/arc-prize-2026-arc-agi-3)／[公式Kaggle Starter](https://docs.arcprize.org/arc-prize-2026)。

## 3. 学習機械による最小のゲーム循環

1. **観測**：公開SDKの画面/フレーム、許される状態表示、合法アクション、レベル遷移、直前の行動・結果を取得。隠れたゲーム答え・未公開状態は禁止。
2. **推論**：事前の汎用記憶と当該ゲームでの観測から、作用→結果の暫定機構・目標・到達手順を推定し、候補の不確実性と根拠を持つ。
3. **採否**：HDS候補の不採用はその候補の不採用に限る。別の判断責任を持つ実行層が**合法・有益・予算内の観測行動/探索**を選べる。自動無審査採用、勝手な根拠創作は禁止。
4. **実行**：SDKが許すゲーム行動を実際に発行。**RESETしただけで終了してはならない**。制限や危険のない通常のゲーム操作を多手数実行する。
5. **結果観測・更新**：画面差分、状態、報酬・到達レベル、失敗署名から機構仮説・短期記憶を更新し、次手を選び直す。
6. **攻略・終了**：公式SDKの終了判定、全クリア、実行予算/ルールによる停止で閉じる。停止理由と使用行動数を明記。**単なるHDS HOLDをゲーム終了と同一視しない**。

公開ゲームの特定IDを見て行動を直接決める分岐、定型軌跡の固定再生、非公開内部状態へのアクセスは行わない。観測された条件/ルールが同じなら同じ機構を別ゲームでも利用できるようにする。

## 4. 既知の致命的な構造欠陥

- \`MyAgent.MAX_ACTIONS = 1\`がゲームの継続を阻み、\`is_done()\`が\`NOT_FINISHED\`でも即停止していた。
- \`choose_action()\`は\`NOT_PLAYED\`時の\`GameAction.RESET\`以外、合法な継続行動を返せていなかった。
- \`検証/test_ARC3提出agent.py\`の既存テストがこの停止挙動を**成功と判定**していた。
- \`接続/共通観測経路.py\`で候補実行許可が全てfalse。HDS判断を偽らず、**外側の許可可能な探索行動**へ繋ぐ必要がある。
- Notebook梱包が一般化記憶を除外。学習機械に過去解析が供給されない。
- 旧提出の\`submission.parquet\`で得点に見えるフィールドがあっても、**Leaderboardのゲーム攻略スコアは別**。

Codexは上の欠陥を単独のコード1行で隠してはならない。**実ゲームで進行し点が付く機能循環全体**を成立させる。

## 5. 正しく計測する指標

**公開ローカル**：ゲーム数、攻略レベル数/分母、完全クリアしたゲーム数、各レベルの行動数、RESET数、無進展行動数、時間・予算切れ数、全行動の観測と結果、公式採点に照らしたローカル効率値（計測できるなら）。形式的な1アクションSDK接続は別項目。

**学習実証**：同じ未見ゲームまたは未見状況で、汎用学習前Aと公開の観測で記憶更新後Bを、同一初期状態・行動予算・seedで比較。観測から作用規則がどう変化し、それが攻略進行や操作数にどう結びついたか記録。異なる評価条件の得点を直接比較しない。

**公式**：Kaggle Kernel版、通常RUN結果、Competition Rerun ID、公式Leaderboard点数、当該版のHDS/記憶hash。PENDINGのまま数値を補完しない。

## 6. 競技制約

Notebook実行上限9時間・無ネット・合法な公開外部データのみ（公式掲示時点）。SDK API・許されるアクション・RESETの扱い・報酬・終了は**現行版の公式資料と実SDK実験**で検証。HDS内部のHOLDを偽のPASSへ変更せず、実行層の役割分離を明文化。**公開ゲームの記憶に過適合した固定攻略を作らない**。

**検収不能**：RESET1手だけ、Notebook RUN COMPLETEだけ、成功軌跡9本を固定再生、他版の23.86を現在の公式スコアとすること、学習状態が変わらないまま学習成立を宣言すること。
