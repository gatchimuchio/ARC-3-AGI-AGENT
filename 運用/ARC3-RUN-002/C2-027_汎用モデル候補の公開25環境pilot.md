# C2-027 汎用モデル候補の公開25環境pilot

## 目的

C2-026でモデル候補が同一公開開始状態・各80 Actionの3環境比較において、local v4 baselineの合計1 levelに対して3 level（差分+2）を得た。差分が1環境だけに依存する可能性と公開環境間のばらつきを確認するため、公開環境一覧順の先頭25件を一度だけpilot評価し、同一開始状態の既存local v4と比較する。

これはprivate開発評価であり、公式Competition Rerun、提出、公式score取得をしない。結果を公式候補への昇格やgeneral capability claimに直結しない。

## 事前証拠

- C2-026 candidate v4: 3環境で完了level `1 → 3`、delta `+2`。WINは0。開始盤面を直接照合し、board/state/levelは3/3一致。
- model kernel: `tecchannn/arc3-model-guided-c2-025`、現行version 4。private、GPU有効、Internet無効、pinned Python 3.12 Docker、入力model/datasetは既存指定を保持。
- local v4 baseline: `public_local_environment_action_response`、seed 31、`max_actions_per_policy=80`、`retry_game_over=true`、記録`出力/ARC3-RUN-002-local/C2-025-v4-public-25-retry.json`。
- baseline JSON SHA256: `5db40eb97823aaf5304c1c9ff40ec64b22618b0d98a5e09de1d61a109f355a31`。
- baselineの25 unique IDはexploration合計3完了level、0 win、2,000 Action、137 no-op。保存artifactの`same_public_start=true`はlocal evaluator内のrandom/exploration一致のみを意味するため、candidateとの開始盤一致証拠としては使わない。補助再評価`C2-026-start-check.json`に25件すべてのbaseline開始盤面が保存済み。
- 最新公式Competition Rerun: `57541830` COMPLETE/public `0.25`。本タスクでは公式提出を行わない。

## 比較・記録

- 25件すべての実出力IDをbaselineへ照合し、ID集合の一致を確認する。各candidate initial eventのboard/state/levelを`C2-026-start-check.json`の同ID exploration initial board/state/levelと直接比較する。`same_public_start`フィールドだけではcross-run一致とみなさない。
- 各IDについて開始状態一致、baseline/candidateの完了level、WIN、Action数、candidate score、board-changeなしAction数、GAME_OVER、invalid action、wallclock、tokensを記録する。
- previous/current/deltaは同一ID集合で集計し、未一致・欠損・time-limit到達を明示する。Kaggle kernelのsummary scoreは公式scoreと呼ばない。
- 出力は`出力/ARC3-RUN-002-local/C2-027-kaggle-output/v5/`へ保存し、主要ログ・event artifact・NotebookのSHA256を記録する。
- Kaggle execution historyとCompetition submission historyを別々に照合する。公式提出履歴は前後とも変化しないことを確認する。

## 実行上限

- 1回のprivate runのみ。25環境、各最大1200秒、最大80 Action、逐次実行。per-game capを全て消費した場合の上限は8時間20分にkernel起動時間を加えた値。
- Kaggle公式Notebook docsは通常GPU/CPU batch session上限を12時間としている（[Kaggle Notebooks](https://www.kaggle.com/docs/notebooks)）。このrunはCLI側にも31,920秒（8時間52分）のtimeoutを設定し、Notebookの内部上限より先に外側で打ち切れるようにする。
- Kaggle側の実行制限・認証・入力取得によりrunが失敗または中断した場合は同じ長時間runを自動再試行しない。取得できた部分結果を保存し、次の指示書へ制約と証拠を残す。
- Private runであっても競技提出quotaを使わない。competition submission API/CLIを呼ばない。

## 採否

- static/runtimeの条件と開始状態一致を確認できた場合に評価結果を受け入れる。
- 25件合計のlevel deltaが正なら、次工程で行うのは候補の失敗分布と一般化確認であり、公式候補への昇格ではない。
- deltaが0以下、比較ID不足、policyへのID依存、runtime/errorがあればpilot不支持として記録し、別の最高優先度タスクへ移る。
- 公式提出・採点は未実施のままとする。
