# C4-002 指示書：レベル間 ACTION6 色統計転移の単独評価

- 指示ID: `ARC3-RUN-002-C4-002`
- 版: 1.0／2026-10-23（JST）
- 根拠: C4-001でAction全体の統計をリセットしてもcompleted levels・完了Action位置は変わらなかった。一方、現行方針はACTION6の色UCB回数・報酬を同一ゲーム内レベル間で保持する。色番号ごとの反応が次レベルへ転移するという仮定だけを検証する。

- previous: 現行candidate v4相当。Action UCB、色UCB、座標試行、公開盤面記憶、乱数状態をすべてレベル間で保持。

- 公開盤面・合法Actionのみを使い、最大80要求、GAME_OVER後のSDK RESETを維持する。ID・盤面hash・既知解・hidden/evaluator stateを使わない。
