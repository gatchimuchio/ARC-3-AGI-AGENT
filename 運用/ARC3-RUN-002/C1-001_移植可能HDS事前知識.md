# C1-001 指示書：移植可能なHDS事前知識の初期化

- 指示ID: `ARC3-RUN-002-C1-001`
- 版: 1.0／2026-10-22（JST）
- 対象: Kaggle ARC3提出agentの新規HDS初期状態
- 基準線: `ARC3-RUN-002_S1-初回公式基準線_20261022.md`、Kaggle submission `57527856`、public score `0.00`
- 前提診断: `ARC3-RUN-002_C0-初回基準線診断_20261022.md`

## 目的と仮説

提出agentは空の `HDS学習系統()` を作り、利用可能な学習状態を初期化していない。Competition bundleも `入力/` と `記憶/` を除外する。仮説は、公開データから得た**ゲーム横断で条件化可能なHDS規則**を安全に初期化できれば、空HDSより適用可能な作用候補を増やせるというもの。

この課題は事前知識の一般化可能性を調べる。Kaggle Action実行経路の変更や公式再提出は対象外。

## 許可する範囲

- `記憶/事前記憶/v0.4/機構作用既知解_HDS正本.json` の「横断蒸留」部分と、既存公開教師から学習済みのHDS状態を調査する。
- game ID・level IDを入力として選択しない、対象role・relation・作用前提・状態差分で記述された規則候補だけを抽出する。
- 学習ゲームと評価ゲームを分離するleave-one-game-out方式で候補生成・支持・反例を測る。
- 比較対象は同じ公開観測に対する空HDS。候補数ではなく、根拠付き規則の再現・別ゲームへの転移・反例でのHOLDを評価する。
- 安全な抽出物が成立した場合に限り、提出用agentが読み込めるseed artifactを小さく生成し、targeted testsで読み込み・出所・決定性を検証する。

## 禁止と保持条件

- `既知解.records`、ゲーム別 `作用実測`、183レベル索引、成功trajectory、答え・再生列・固定座標列を提出物に含めない。
- 抽出規則の条件・値・候補をgame/level IDで分岐・検索しない。任意のルール除去で意味を保持できない不透明な一括pickleを使わない。
- hidden state、非公開評価器、Kaggle testの正解へアクセスしない。
- `HDS/学習系統/v0.4.2`、`制御/現在状態.json`、AGENTS.md、既存記録・入力を変更しない。既存の候補 `実行許可:false` をtrueへ書き換えない。
- learner/connectorの実行許可が未確認の候補を、seed生成の成功扱いにしない。

## 検証

1. 入力データの出所、保持範囲、ゲーム固有情報・解答相当情報の境界を確認する。
2. 一部ゲームで学習し、別のゲームを完全にholdoutした転移測定を複数分割で行う。
3. 空HDSと同一観測で比較する。根拠付きの適用候補数、正例再現、holdout別転移、反例HOLD、例外・不明率を記録する。
4. seedの再生成決定性と、提出bundleに識別子・trajectory・answer mapが混入しないことを検査する。
5. 非負の転移・反例保持の基準を満たさない抽出物は不採用とし、提出agentへ接続しない。

## 終了条件と次の仕事

- 根拠付き横断規則を持つ安全なseedが成立し、leave-one-game-out転移と反例HOLDが確認できればC1 PASS。previous/current/delta、適用条件、失敗署名を保存する。
- 成立しない場合もC1をFAIL/棄却として記録し、答え表を使わない別の優先課題へ移る。
- この有限単位の結果を保存した後、次は別指示書で「HDS確定作用と独立した探索Action経路」を検討する。C1の合否で継続を停止しない。
