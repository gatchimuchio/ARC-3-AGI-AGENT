# C2-004 可視変化報酬の単独検証

## 仮説

C2-002では複数報酬係数を同時変更して不採用となり、因果は分離できなかった。今回は可視盤面の変化量報酬だけを `0.25` から `0.0` に変え、画面変化がレベル進行に結び付かないActionを過大評価していないかを確かめる。

## 比較条件

- 現行v4と、可視変化係数だけを0にした試験方針。新盤面ボーナス、レベル進行報酬、no-op罰、UCB係数、Action候補は固定する。
- 既存split seed `20261022`。開発5環境をAction seed 7/31/73、各80 Actionで比較する。
- 開発側でcompleted levelsを維持し、3 seed中2 seed以上で完了Action数またはno-opが改善し、GAME_OVERを増やさない場合に限り、未使用holdout 20環境をseed31で一度評価する。
- holdoutではcompleted levelsを維持し、完了Action数とno-opを悪化させず、GAME_OVERを増やさない場合のみ採用候補とする。係数調整はholdoutで行わない。
- runtime候補を変えるのは両段階の条件を満たした後だけ。Kaggle公式scoreやhidden評価はローカル結果から推定しない。

## 実装

`観測駆動探索方針` に可視変化係数を明示パラメータ化し、既定値 `0.25` を維持する。ローカル評価器から値を指定する。game/level ID、filename、hashでのruntime分岐は行わない。

## 完了条件

採否と全seedの結果を `検証/運転記録/ARC3-RUN-002_C2-004_可視変化報酬評価_20261023.md` に記録し、成立しなければruntimeデフォルトを変えず次課題へ進む。
