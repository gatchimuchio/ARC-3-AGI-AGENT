# C2-010 公開進行Action前後の集約診断

- 対象: 保存済みのC2-003 version 4相当のholdout実行結果、seed 7/31/73。
- 目的: 公開holdoutでレベル進行を生んだActionと、その前後に保存されている観測可能指標を集約し、次の行動改善仮説に使える根拠があるか判定する。
- 原因仮説: 進行した遷移に再現可能なAction種別または応答特徴が現れていれば、問題固有情報を使わない横断仮説を立てられる。
- 変更範囲: 既存JSONの読み取り専用集計のみ。agent、探索方針、HDS、Kaggle Notebook、公式提出を変更しない。
- 保持条件: game/level ID、盤面hash/fingerprint、固定軌跡、問題専用条件を特徴量・選択規則にしない。個別ゲームの結果を出力しない。
- 入力: `出力/ARC3-RUN-002-local/C2-003-after-holdout-seed-{7,31,73}.json`。
- 集計: Action別の総数、no-op、可視変化、新規盤面、level進行、GAME_OVER、および進行直前Actionとの組合せ。個別ゲームを識別できない集計だけを保存する。
- 反証条件: 進行例が少ない、指標が作用後にしか観測できない、またはAction6以外の十分な比較例がなく、次の一般化可能な選択規則を定められない。
- 完了条件: 入力hash、集計出力hash、前後比較、サンプル限界、採否、次の優先課題を運転記録へ残す。

この診断で採用可能な行動特徴が成立しなければ係数の追加調整は行わず、現行候補version 4の次回Competition Rerun用状態を保持して、日次枠・期限を再観測する。
