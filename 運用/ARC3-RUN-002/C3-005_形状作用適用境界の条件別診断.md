# C3-005 指示書：形状作用モデルの適用境界を条件別に診断

- 指示ID: `ARC3-RUN-002-C3-005`
- 版: 1.0／2026-10-23（JST）
- 根拠: C3-004で初回dev公開観測5件の形状目標対応から目標候補25件が得られた一方、形状作用適用性は5件とも構造上不適用で、作用候補0と確認した。現行作用モデルは二つの3×3対象・二つの可視3×3目標等に限定されるが、今回の5件でどの条件が不一致かは未分類。

## 目的

C3-004と同じ固定dev先頭5公開環境・同じseedから初回 `NOT_FINISHED` 観測を取り出し、既存形状知覚と作用適用ゲートが参照する構造条件を個別の真偽として匿名aggregateする。作用ゲートの不適用がどの条件で起きているかを特定し、次の単一課題を選ぶ。

## 固定条件と保持範囲

- Split seed `20261022`、environment seed `31`、先頭5環境の初回進行中公開観測各1件。
- `形状場面を読む` と `形状作用の範囲を読む` の既存read-only関数のみを使う。
- board dimension, target/object count, supported shape and completeness, target/object count compatibility, model object-color compatibility, absence of transport candidates, unique selection, and actual gate statusを条件別に計数する。
- 出力には総数・真偽のaggregateのみ保存する。game/level ID、GUID、盤面、色値、座標、形状・対象の生内容、Action、理由文、観測fingerprintは保存しない。
- HDS照会・学習、Action要求、候補実行、runtime/agent/HDS/Notebook/kernel変更、Kaggle/GitHub操作は禁止。
- `AGENTS.md`、`制御/現在状態.json`、C3-004成果物は変更せず、旧出力は上書きしない。

## 受入条件

1. 初回進行中観測5件を処理し、C3-004の「形状作用適用性5/5構造上不適用」と矛盾しないこと。
2. 条件別aggregateの和が各5件となり、出力へ個別環境の対応関係や禁止データが漏れないことをtestする。
3. HDS照会・学習とAction要求が0であることをコード境界で確認する。
4. targeted tests、Ruff、format check、py_compile、CLI help、`git diff --check`を実行し、source/input/output SHA-256を保存する。
5. 条件不一致の実測から次の単一課題を選ぶ。条件を緩める変更は本タスクでは行わない。
