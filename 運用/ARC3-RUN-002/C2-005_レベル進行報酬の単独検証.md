# C2-005 レベル進行報酬の単独検証

## 仮説

C2-002はレベル進行報酬を `4.0→16.0` と複数係数同時に変更して不採用になった。因果を分離するため、今回はレベル進行報酬だけを `4.0→8.0` にする。進行Actionが同一ゲーム内の後続levelで再選択されやすくなるかを見る。

## 比較条件

- 現行v4とレベル進行係数だけを8.0にした方針。新盤面0.5、可視変化0.25、no-op罰-1.0、UCB係数、Action選択・座標方針は固定する。
- split seed `20261022` の開発5環境、Action seed 7/31/73、各80 Action、GAME_OVER後RESET有効。
- 開発で全seedのcompleted levelsを維持し、2/3以上のseedで完了Action数またはno-opが改善し、GAME_OVERを増やさない場合のみ未使用holdout20環境をseed31で一度評価する。
- holdoutでcompleted levelsを維持し、完了Action数・no-op・GAME_OVERを悪化させないことを採用候補条件とする。holdoutでは係数を調整しない。
- 条件未達ならruntime既定値4.0を保ち、候補Notebookを更新しない。ローカル評価をKaggle公式scoreと混同しない。

## 実装

`観測駆動探索方針` のレベル進行係数を引数化し、既定値4.0を保つ。ローカル評価器から実験値を渡す。game/level ID、filename、hashによるruntime分岐は禁止を維持する。

## 完了条件

結果・artifact hash・採否を `検証/運転記録/ARC3-RUN-002_C2-005_レベル進行報酬評価_20261023.md` に記録する。
