## 大きな実行ログの復元

大きな自前の実行証拠は可逆XZ圧縮し、原本を作業機で保持する。`large-evidence-archives-xz.json` に原本/圧縮物のpath・size・SHA-256を記録し、圧縮後の全streamを元hashと照合する。GitHubに保存するのは圧縮物で、元の参照pathは復元後に使う。

```powershell
python 道具/圧縮証拠を復元する.py --verify-only
python 道具/圧縮証拠を復元する.py
```

異なる既存ファイルは上書きしない。復元はリポジトリ内に限定する。raw byteを参照する凍結証拠はGit保存による改行正規化も照合し、旧hashを書換えて整合を作らない。
