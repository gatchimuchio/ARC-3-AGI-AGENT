# HDS

HDSはARC3世界の**入力主体・判断主体・出力確定主体**である。

HDSコンパイラはHDSの内部機能であり、独立主体ではない。

## 管轄

- 世界観測
- 対象化
- Frame形成
- 目的保持
- 問い生成
- 境界設定
- データ選別
- ミニドラ入力へのコンパイル
- ミニドラ出力の評価
- 反証・フィードバック
- 再計算要求
- Gate
- Action確定
- 因果帰属
- 記憶更新採否

## 実装原則

ARC3のraw observationをそのままミニドラへ流さない。
HDSが「現在何をデータとして扱うか」を確定し、必要な文脈・問い・記憶参照条件とともにコンパイルして渡す。

フルスペックHDS/HDS-BBの実装内容は今後ここへ追加する。
