# AGI三主体構成

## 不変式

```text
AGI = HDS + LLM + 記憶
LLM = ミニドラ
HDSコンパイラ ∈ HDS
```

## 責任境界

### HDS

ARC3世界との境界を所有する。

```text
世界受領
→ 観測
→ 対象化
→ Frame
→ 目的・問い・境界
→ HDSコンパイル
→ ミニドラへの入力
```

ミニドラ出力後もHDSが責任を持つ。

```text
ミニドラ候補
→ 評価
→ 反証
→ フィードバック
→ 必要なら再計算
→ Gate
→ 確定
→ ARC3へ作用
```

作用後は再びHDSが世界を受け取り、因果帰属と記憶更新を行う。

### ミニドラ

HDSから渡されたコンパイル済みデータを計算するLLM主体。

```text
入力
+ 記憶参照
→ 仮説
→ 反対仮説
→ 推論
→ 計画
→ 命令形
→ 作用候補
```

候補は確定ではない。世界への直接作用権限を持たない。

### 記憶

判断根拠を保持する可変主体。

```text
Prior Memory  = 事前にHDSで解析・蒸留した知識
Runtime Memory = 現在の実行から得た知識
```

HDSの判断によって内容を更新する。

## 外側cycle

```text
ARC3世界
→ HDS
→ HDSコンパイラ
→ ミニドラ ⇄ 記憶
→ HDS
↳ 未確定: ミニドラへフィードバック
↳ 確定: ARC3へ作用
→ 世界変化
→ HDS
→ 因果帰属
→ 記憶更新
→ 次cycle
```

この責任境界はARC3攻略戦略とは独立した上位構造として固定する。
