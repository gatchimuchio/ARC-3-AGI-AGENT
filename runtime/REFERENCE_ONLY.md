# Runtime reference boundary

`runtime/` is documentation-only and read-only in `PH-D00B`.

No Python module, package, entrypoint, executable artifact, Bridge component,
agent capability, or fallback may be placed here. The historical
`ARC-AGI-3-Agents/` implementation is not copied or imported.

A distilled AGI Runtime may begin only after the ordered distillation and
Bridge phases have produced the required Owner-approved and frozen bundles.
