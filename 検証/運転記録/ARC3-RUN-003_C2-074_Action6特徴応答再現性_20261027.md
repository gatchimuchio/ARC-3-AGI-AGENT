# C2-074 Action6特徴と進行応答の再現性

## 目的

Action6の選択時公開特徴「選択セルの可視色」がレベル進行応答を予測する十分な反復信号を持つか、V6現行方針で確認した。C2-072/073のcredit倍率試験後に、少数イベントに対する色別学習を追加する根拠があるかを評価する。

## 条件

- 公開環境25件、environment/policy seed `401, 503, 607`、計75 episode。
- 各episode最大80 actions、可視変化係数0.0、level-progress報酬4.0、現行観測駆動探索方針。`PYTHONHASHSEED=0`。
- 公開状態と公開Action応答のみ。ゲーム別行を保存せず、Action ID・選択色別に集約。進行イベントの異なる公開ゲーム数はゲーム識別子を保持せず、実行中の連番indexだけで数えた。
- 公式API・提出・quota・Notebook/kernel操作なし。

## 結果

75 episode、5,189 actions、no-op457、level event 8、完了level8、WIN0、illegal/error/duplicate observation 0。local exploration RHAE平均は`0.195250`（seed401: `0.197744`、503: `0.273726`、607: `0.114280`）。これはbaseline policyとのpaired差ではなく、今回の探索方針の記述統計である。

進行イベント8件はすべてAction6で、選択可視色別には色5が179 actions中1件・1ゲーム、色8が238中3件・1ゲーム、色9が227中4件・2ゲーム。Action1–5/7ではイベントなし。色8/9へイベントが集まるように見えるが、反復は公開25ゲーム中3ゲームに限られ、色8の3件も同一ゲームに集中している。色だけを説明変数にして未知ゲームへ転移する根拠として不足する。

### 採否

色別credit・優先度のcandidateは作らず、runtimeへ変更を加えない。現在の学習機械は行動応答に応じてrun内報酬を更新するが、このデータではAction6色から再利用可能なcross-game ruleを作るだけの独立した成功例がない。次は、色単独でなく盤面の公開配置・近傍・直前遷移を含む状態特徴が、複数ゲームにまたがって進行前に反復するかを調べる。candidate選定はdevに限定し、別ゲーム/seed holdoutとHDS agentの同条件scorecardを通す。
