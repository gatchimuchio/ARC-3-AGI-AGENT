# 教師証拠の被覆と公式接続の現状確認

## 目的

既存の教材・観測・失敗記録が、どのゲームについてどこまで一次証拠に接合しているかを再確認する。公式接続の失敗も原記録として保持する。現行実装の採用状態、HDS、AGENTS、権限順序、現在状態は変更しない。

## 観測

- 25ゲーム・183レベルと初期一手5112件は、保存済み索引と集計である。5112件全部の before/action/after 生記録が接合されたという意味ではない。既知9成功列の参照も現在のfresh再現を証明しない。
- 初期packetは重複コピー50件を照合し、25固有packet・27frameを確認した。
- 今回選んだ公開recording 6件は3ゲームに属する。残る22ゲームについて、調べた資産内では検証済み因果列の閉包を確認していない。全世界・全履歴に存在しないという証明ではない。
- 列図式の失敗記録は1,797 memberのhashを確認した。90 response packet、1,812 phaseはいずれもNOT_FINISHEDであり、途中の進捗値6をfresh認証済み6レベルとは数えない。
- 過去の切断recordingはdecode失敗を残したまま保持する。完全版と重複しており、独立した新規データではない。
- 25/183の索引、過去のWIN終端、今回の照合件数はいずれも新しいagentのクリア実績ではない。認証済みfresh成功は引き続き1/183、約0.55%。フルゲームWINは未達。

## 原因と変更

過去の「全数観測済み」という集計だけでは、教師として再利用できる因果列の所在・版・結合関係を説明できない。また現在の公式接続はDNS段階で止まり、保存資料の時点と現在のサービス状態を分離する必要がある。

今回追加するのは、既存資料のhash照合、被覆表、制約を明示した報告、失敗した接続試行の生記録である。SDK/gameの不透明な実装本文、認証情報、未完了の新規実験は含めない。原資料の変更、native Query/Teach/Action、runtime採用は行っていない。

## 公式接続の結果

- three.arcprize.org と arcprize.org の認証なしGETは、記録された実行環境ではDNS解決に失敗した。HTTP response/statusは得られていない。追加の実行許可を用いた試行は実行前エラー、別cloud containerもDNS失敗であり、その696-byte報告は元hashと一致する。
- ウェブ取得失敗もHTTP到達やサービス停止の証明に読み替えない。匿名API keyの作成・取得、SDK起動、環境Actionは行っていない。
- 公式benchmarking側の参照はarcprize.org、SDK側のdefault参照はthree.arcprize.orgで共存する。これだけで全経路の移転・redirect・認証不要を断定しない。参照した上流mainの生ファイルとcommitはこの監査で固定できていない。
- 保存された2026-10-13の25/183 metadataを、現在のサービス一覧の再取得結果とは呼ばない。旧SDK metadataの存在も、現在のSDK importや実行成功の証明ではない。

## regression / 保存

公開入力、6 recording、失敗packetの選択された元bytesを独立に再照合した。初期の誤分類・manifest検査失敗、後続訂正は別fileとして保存する。独立監査自体の失敗もsource/stdout/stderr/exitstatusとともに保持し、大きな成功stdoutのみ正確なhash付きで可逆圧縮した。未捕捉だった最初の名前一覧操作は欠落として明記し、記録を捏造しない。

直前の候補診断publication receiptには、OS引数長制限とbase64改行比較による失敗、その訂正、実際のGit応答、CI結果を含む。過去のprivate属性は過去のsnapshotであり現在の公開状態を示すものではない。

## limitations

- 調査対象を明記した証拠監査であり、全作業・全履歴・全183レベルの完全な因果閉包ではない。
- 既存のfresh043資料、358,669-byte歴史解析、その他未復旧の原証拠欠落を埋めるものではない。
- 今回のHDS文書検査は、この追加payloadと内包receiptに限る。実装のimport/API参照、ARC3事前記憶の射影、path/hash参照があるが、HDS原典・正本仕様本文を収録するものではない。repository全履歴に原典が絶対に存在しないという保証ではない。
- 22ゲームの不足、version差、隠れた状態、解釈不能phase、固定prior依存は残る。新しい教師設計や他ゲームへの汎化は未検証。
- 次の実環境接続・学習は別の許可・resource gate・検証単位で行う。
