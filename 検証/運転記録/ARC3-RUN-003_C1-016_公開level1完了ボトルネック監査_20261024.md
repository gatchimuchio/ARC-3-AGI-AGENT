# ARC3-RUN-003 C1-016：公開level 1完了ボトルネック監査

## 結果と判定

- 正本 `運用/ARC3文書正本.md` が指すv3.0に従い、公開25環境、split seed `20261022`、environment/policy seeds `7/31/73`、最大80 action/run、GAME_OVER後RESET有効で実測した。
- 75 runでlevel 1完了は8、level 2到達は0、WINは0。これはC0-001の公開RHAE baselineと一致する。
- level-progress応答は全8件が`coordinate`群にあり、seed別に`2/3/3`件。`discrete`群は0件だった。候補特徴は3 seedすべてに出たが、事前基準の「該当機会10件以上」を満たさないため、C2へ進む支持根拠は不足と判定する。
- `coordinate`群では選択1,886件中、no-op 291、board-change-without-progress 1,561、level-progress 8、game-over 26。`discrete`群では選択4,067件中、それぞれ156、3,890、0、21。これは記述的な集計であり、因果・有効性を示さない。
- 出力はseed・action群別の集計に限られ、level 1完了run内外に分けた機会数を持たない。よって完了runとの関連の方向も算出しておらず、8件を因果証拠として扱わない。
- C1-016は「公開level 1進行機会が少なく、事前件数閾値に届かない」という停止判定で閉じる。C1-016からC2は作成しない。既存UCB・state-context・seed等の再調整も行わず、独立した公開根拠が得られた場合に限り新しいC1を定義する。
