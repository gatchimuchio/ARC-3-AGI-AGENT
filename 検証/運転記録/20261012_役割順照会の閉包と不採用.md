## 目的

公開教師から横断的な状態・条件・操作規則を現行 Learning Machine で学習するため、同じ観測の対象順だけを入れ替えた際の返却差を切り分ける。

正常閉鎖済みの 3 教示 checkpoint を fresh process へ標準復元し、5 公開 Action の原順／swap を計 10 回照会した。fresh environment の攻略試験ではない。追加教示・新支持は 0。

## 観測・変更・原因

B は before-only 観測の一意な役割に従って対象全体の並びを揃える接続試験である。各対象内の全値・型・順序は保持し、元対象への全単射を外部証拠に保存した。native API へ渡すのは内容と対象系境界のみ。末端実測は外部採点に限定し、照会に作用後情報を入れていない。

- 既存 3 教師の B 入力は、従前の教示入力と全型・順序で等価。
- 観測済み役割の重複・不明等は別途保留し、ID・色・座標を並びの決定に使わない。
- game / level / Action 行番号 / filename / hash は証拠選択・照合だけに使用。
- HDS/学習系統/v0.4.2、HOLD、支持・反証、採否、authority は無変更。
- 未充足数を加える別案 A は混合していない。

B で下記 5 組の返却差を消せたことは、従前の差に外部の対象表現順が関与していた証拠である。ただし誤予測も同じ値へ揃った。規則内容の正しさ、HDS 一般の順序非依存性、未観測の物理因果まで証明したものではない。

## 採否・limitations

B は runtime 不採用。931 swap の既存正答を失い、全件 HOLD も継続したため、正本 runtime を変更しない。試験は隔離されており runtime 経路へ統合していないので、runtime の変更を戻す操作は不要だった。

開発用の 5 公開 Action であり盲検評価ではない。同じ Action の別表現を新経験・新支持・独立成功と数えない。役割が重複する対象群への一般性も未成立。新教示・環境 Action 実行は行っていない。次は別案 A の既存目標相対量を前提へ接続し、同じ公開教師から fresh 学習する独立試験へ進む。B と A の効果を混合しない。
