## 方法

HDSへ渡した条件はAction番号だけ。結果は「可視変化あり」「level進行あり」「新規盤面あり」の真偽値だけで、RESETは除外した。各gameのAction列の先頭75%を`処理する()`で記録し、後半25%は結果値を入力せず`照会する()`だけで予測を採点した。多数派予測とAction別多数派予測も同じ後半サンプルで比較した。

| 指標 | 実測 |
|---|---:|
| 環境 | 5 |
| HDSへ学習入力した公開Action応答 | 294 |
| HDSの後半read-only照会 | 100 |
| 学習後／照会後の経験台帳件数 | 各環境で一致（58, 58, 59, 60, 59） |
| 最終状態版が0より大きいHDS | 4/5 |
| 最終有効原理数 | 3, 3, 0, 3, 4 |
| HDSの後半単一予測 | 100 |
| HDSの後半正答 / 誤答 | 100 / 0 |
| 同じ100件への多数派正答 / Action別多数派正答 | 100 / 100 |

HDSは4環境で状態版・原理を更新したが、後半予測は多数派基準と同じ正答に留まった。予測内容も、一部Actionの「進行なし」や「可視変化あり」を出すに留まり、既存基準を上回る判断情報はなかった。新規盤面ありの予測coverageは1環境20件だけで、これも多数派基準と同じ20/20だった。したがって、状態更新は観測できたものの、有用な学習・転移・性能改善は成立していない。

一部の原理が入力要約上で結果間の対応を作っているが、ゲームごとに独立したHDSを使ったためcross-game transferの証拠はない。100件の完全一致だけを学習成功やActionの因果証明とは扱わない。
