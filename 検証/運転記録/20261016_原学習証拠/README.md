## limitations

- 原アーカイブには過去の失敗・不採用・古い source・絶対パス参照がある。取得できることと、現環境でそのまま実行できることは別であり、runtime 採用を意味しない。
- 準備・保存アーカイブに自作 `prepsave_guard_v1.cpython-312.pyc`（5,113 bytes、SHA256 `473378f99a8bd53c6ba2d54c675d2792fca2a63a139271fa59ce365b4b0ffe53`）が 1 個ある。原本保存のため残し、hash 照合のみ。bytecode の意味を認証したとは主張せず、実行しない。
- 公式 game / SDK 実装の本体や秘密情報は収録しない。記録内の外部依存 FileRef は参照先の本体が保存されたことを意味しない。公開録画の利用許諾を独立に確定したという主張も行わない。
- 学習効果の根拠は記録された条件内に限る。未観測の hidden state、別ゲームへの汎化、全称的な正しさや速度改善は未証明。
- saved118 診断、fresh 成功・失敗の他アーカイブ等は後続保存の対象。この追加だけで「全部保存済み」とはしない。
- 再起動直前の fresh043 実行と一部後続 source / fixture / 解析依存は未復旧。欠落を要約から再生成しない。復旧範囲は前の復旧チェックポイントも参照する。
