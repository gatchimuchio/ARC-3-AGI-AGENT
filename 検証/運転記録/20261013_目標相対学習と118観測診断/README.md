## 収録範囲と読み方

[checkpoint索引](checkpoint索引.json) は既送8archiveの名前・bytes・SHA256を示す。hashは統合作業時に既存archiveのbyteから再計算した。`原報告/` と `検証票/` は各checkpoint時点の原文をbyte同一で保存した。過去の「Git許可待ち」「診断未完了」等は当時の履歴であり、この索引の現在時点と区別する。
`独立監査/` の `.json.gz` は原JSONを内容変更せずgzip圧縮したもの。`証拠マニフェスト.json` に原本と収録後双方のbytes・SHA256を固定する。

この最初のcommitには報告・監査・検証票を収録するが、全raw native corpusやarchive本体は含めない。ローカル絶対pathは履歴上の出典であり、GitHub上で開けるリンクでも自己完結した再現環境でもない。資料全体を取得せずに原監査を再実行できるとは主張しない。別のbounded commitで、公開可能性を確認した学習checkpoint本体を追加する。
