# ARC3-RUN-002 C1-003 公開応答複数frame監査

- 実施日: 2026-10-23 JST
- 指示: `運用/ARC3-RUN-002/C1-003_複数Frameの情報利用監査.md`
- 判定: **観測監査PASS。runtime変更・能力改善の主張なし。**
- 対象: Kaggle由来25公開環境、候補v4相当の現行探索方針、action seed 31、1ゲーム最大80要求、GAME_OVER後SDK RESET。

## 入力と測定

公式starter `arcengine`の`FrameDataRaw.frame`はruntime上のgrid配列であり、starter `Agent`は各gridを`FrameData.frame`へコピーする。現行境界`観測する()`も全gridを`観測.盤面列`へ保持する。一方で探索Action選択とHDS公開候補照会は`観測.最新盤面`だけを参照し、他の応答gridを選択・報酬に使わない。

診断は実際の各応答からframe列を読み、追加のAction・SDK step・環境改変なしでgrid数とセル差分を集計した。game名・IDはartifactに出力しない。監査後のAction要求合計2,000は、既存seed31のdev 400＋holdout 1,600と一致。Action経路は現行policyのまま。

## 結果

- 25環境すべてを実行。15/25環境で複数grid応答を少なくとも一度観測。
- 2,000 Action応答に含まれたgrid数は合計7,833。複数grid応答は654（32.7%）、応答内の異なるgrid数合計4,443。
- 最終gridと異なる中間gridは応答ごとの合計2,443。途中で以前の値に戻ったセルは重複を含む43,632 cell-occurrences。比較不能遷移0。
- ACTION5は174応答中127件が複数gridで、合計3,848 grid（平均22.1 grid/response）。この傾向はAction種別の集計に留め、用途・意味は推定しない。
- ACTION6では631応答中241件が複数gridで、途中で以前の値へ戻るセルが25,021 occurrences。

この結果は、候補のAction/報酬判断が実際に使っていない公開frame列が広く返ることを示す。ただし途中gridの意味、行動上の情報価値、level成功への因果は未確認。従って中間gridをruntimeへ接続しない。
