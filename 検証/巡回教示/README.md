# 教示保存gate改訂1

旧教示拡張freezeを保持。旧CLIは部分書込失敗/意味不一致でも最終pathを残すため採用しない。本改訂のCLI/fixtureを採用する。旧fixtureと同じ全94教師/4照会を含み、さらに独立監査の具体1576時刻leaf位置と原時刻を追加する。runtime7は無変更。

実験再生成における差分は具体1576pathのISO時刻のみである。それぞれの値がtimezone付き時刻であることを確認し、そのpathだけ原時刻へ置換した比較用copyの全構造SHAを照合する。保存実体は新しい実時計のまま。「時点」「対象期間」という名前のキー全体を除外しない。指定外の同名キー差分は検出される。元の入力、ID、照会台帳、状態、原理、根拠を含む全構造を検査する。

保存は同じdirectory内の新規未完pathへ行い、JSON意味照合と標準HDS再読込、fsync後にhardlinkで新規最終pathへ確定する。hardlinkは既存pathを上書きせず、最初の存在検査後の競合にも耐える。親dirもfsyncする。成功時だけ未完linkを外す。失敗時は未完byteと理由JSONを別artifactとして保持し、例外の失敗記録から参照を返す。最終pathがすでに存在する場合は学習前に拒否する。ディスクが一切書けない場合は理由保存も保証できず、その例外も返す。確定後の親fsyncだけが失敗した場合は内容検査済み最終pathが存在し得るが、確定完了として報告せずその存在を失敗記録に明記する。

既存接続/観測駆動一巡.py の未完証拠保持/fsync/失敗参照契約を参照した。親の非上書き条件に合わせて最終操作はreplaceではなくlinkを使用する。未完一時byteを削除する前案は未採用zipとして保存。

```sh
python -B -m unittest discover -s "$REPO/検証/巡回教示" -p 'test_*.py' -v
```
