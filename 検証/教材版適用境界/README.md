- 72公開原票（成功25、開発利用済みholdout25、失敗22）を全行逐次確認し、原票SHA256とframe行数はmanifest全件一致。複合教示の追加既存ft09原票1件もfixture SHA256・完全game_idを確認。

- fresh環境初期化・API通信・Action送信・HDS再学習なし。現在環境版は未実測。新規API key取得は行っていない。

主72原票は44,347 frame-record、初期/RESET/完了数遷移の観測イベント864件。RESET action観測444件、full_reset=Trueは0件。記録時点は2025-11-10から2026-03-20で、公開日時と区別する。failure資料がないのはlp85/r11l/sc25。prior metadata自体に取得・実測日時はないため、教材より新しい/古いという順序は断定しない。

## 記録と再検証

教材版適用境界.jsonは全25版索引、公開URL/SHA256/記録時点、183枠のprior metadata・教材側観測参照・画素比較、7教示系のrepo出所を含む。秘密・credentials・人名は含めない。sessionは公式公開原票の参照ID。

python 検証/教材版適用境界/検証する.py --repo . --teachers /path/to/existing/arc_official_teachers

検証は既存ファイルの読取のみ。取得、環境初期化、学習、出力ファイル作成はしない。原票を一つずつ読みSHA256・完全版ID・level数・参照画素hashを確認する。原票内のscore/win_scoreは旧外部形式、levels_completed/win_levelsは新外部形式として読み分ける。

画素hashは64×64全体の整数配列をUTF-8 JSON（separators=(',', ':')、ensure_ascii=False）にしてSHA256。HUDを除去せず末尾相を記録する。末尾相は必ずしも原始作用直後、完成画素、次問題初期画素とは限らない。完了数+1は候補ordinalのみ。game/level/session/hashは索引と証拠照合だけに使いruntime解法分岐へ流用しない。

既存接続/ARC3境界.pyは公開完全game_idを観測に保持し、異なるgame_id間の差分形成を拒否する。これは版の同一性を必要条件として検査する機能であり、教材と現在環境の一致証明やprefixごとの解法選択ではない。接続/観測駆動一巡.mdが定める記録観測照会にも環境stepはない。

この監査候補は自己所有フォルダにのみ作成。core、main、AGENTS、現在状態、remoteは変更していない。
