# 記憶

記憶はAGI三主体の**判断根拠保持主体**である。

## 二層

### Prior Memory

実行前にHDSで解析・構造化・蒸留して格納する知識。

想定対象:

- 定石
- 因果
- 状態遷移
- 目的構造
- 成功条件
- 失敗条件
- 適用境界
- 反例
- 命令形
- 命令形間関係

### Runtime Memory

実際のARC3実行中に得た観測・作用結果・因果・修正知識。

## 更新

記憶は単純加算しない。

```text
追加
改訂
統合
分割
置換
無効化
削除
巻き戻し
保管
```

をHDS判断で行う。

公式サンプルの正解をHDSで完全解析し、事前に蒸留済みPrior Memoryへ変換する方針は、今後の戦略で具体化する。
