# 関節線の独立候補接続

固定 HDS v0.4.2 の学習済み object を明示注入する候補専用 API。共通 dispatcher には登録しない。環境 step・API・追加学習・固定 action 列 lookup はない。全出力は実行許可=False、採用順序=[]、後続事象未閉包HOLD。fresh 成功は0。

## 採用対象7ファイル

- 接続/関節線接続.py
- 接続/関節線因子.py
- 接続/関節線接続.md
- 検証/関節線接続/検証する.py
- 検証/test_関節線接続.py
- 検証/資料/関節線/初期6問.json.gz
- 検証/資料/関節線/実1012r2全126照会.json.gz

runtime の依存は NumPy と固定 HDS の外部入力のみ。他の既存接続module、録画、fixture、保存候補行列に依存しない。呼出側は HDS/学習系統/v0.4.2 を Python import path に置く。試験 helper はリポジトリ内のこの固定pathが存在すれば追加する。分離候補を試験する場合は PYTHONPATH で同じ固定HDSを指定する。

## 入口と境界

`関節線候補を作る(frame, available_actions, hds, 観測履歴=None, 資源枠=None)` は64×64整数画素とSDK作用一覧から役割と全条件族を構成する。Action6があれば4096全座標を保持する。型不正、SDK0..7外、重複Actionは全入力HOLD・照会0。未知palette値、役割未説明画素、帰属不明はHOLD。未知の合法作用も候補域に保持し、自動RESETは追加しない。

`関節線候補族に含まれる(bundle, action)` は所属判定のみ。`関節線観測を照合する(観測履歴, 実観測作用, 全応答相, hds, 公式進行観測=False, 終局観測=False)` は過去prefixから全不変/全選択/選択端移動の枝と全相を照合する。試行相と巻戻り/安定相は別。局所点滅、局所受理候補、公式進行も別フィールド。呼出側は持込む履歴が実際の過去観測由来であることを保全する。

固定部分は END/CIRCLE/RING マスク、可視線連結、全端点分割、floor平均、mask色代数、直積と相対幾何。学習部分は同じ注入HDSの69作用/167完成色/263色合成/950位置/980表示/1012r2型付き取得関係。規則値は注入せず照会し、明示「出力」、非空一意、型・語彙契約適合を全て満たす場合だけ局所支持とする。空/断定保留/未知状態/照会例外はHOLD。予測値のTrue/1、tuple/list、string/intを同一視しない。

準備選択は各端点×全4096クリックを実地形と矩形ヒット/HDS根拠で全数分類する。中間状態も全準備クリック述語を保持する。数値の存在判定は少なくとも一つ準備があることだけを示し、全準備action列を支持する意味ではない。

分割・色DAG・割当・事象・端点族に資源境界がある。超過時は全候補数/上界・全未評価域の記号定義を残した全体HOLDへ切替え、先頭やtop-kだけを採用しない。

## 支持と未成功

教師は公開 r11l-aa269680 の2録画、6問題。別録画も開発使用済みでblind評価ではない。教師内第5像では160事象族、76端点族、6400供給目標割当、第6像では2359296割当を因子化できる。色DAGは25/16086状態、再取得60/99489辺はHOLD層。

旧凍結と独立監査では52族の全536952832座標組、353クリック+6RESET/1405応答相を照合した。これは固定有限候補族内の教師回帰で、全世界軌道やfresh成功ではない。このportable wrapperはその巨大再計算をしない。

3以上端点、同端点再移動、将来の供給可視性、描画重畳、後続6事象、全画素/hidden、公式成功の必要十分性は未閉包。main67/68の9白画素は役割未説明HOLD、main183/184の同色再訪と189の他個体再訪も一般化HOLD。色の最後出現同値性は最終色のみで経路/可用性へ転用しない。色0を捨てず、標識6と供給色6を無条件に混同しない。未観測の両役割併存は未確認。

## 外部stateと実試験

- ARC_JOINTED_LINE_HDS_STATE: 実1012r2のJSONまたはgzip path
- ARC_JOINTED_LINE_COUNTER_STATE: 独立監査で保存した人工反証1013のJSONまたはgzip path

runtime はenvやfileを読まない。envを読むのは試験helperだけ。未設定時、unittestは該当実state試験を明示skip、CLIは終了2。空stateへの代替、再学習、ネットワーク取得はしない。読込は復号SHA検査、1state直列、一時raw101MiB以内。HDS処理するを拒否し、照会後の全保存意味を比較する（照会/学習判定カウンタ2個のみ除外）。

リポジトリrootで、PYTHONDONTWRITEBYTECODE=1を指定する。

- `python -m unittest discover -s 検証 -p test_関節線接続.py -v`
- `python -m 検証.関節線接続.検証する --kind empty`
- `ARC_JOINTED_LINE_HDS_STATE=/明示path python -m 検証.関節線接続.検証する --kind real --output /新規結果.json`
- counter試験はkind counterとCOUNTER_STATEを使用する

unittestはempty/real/counterをそれぞれ直列の新規processで実行する。共有Available2GiB未満は新規readを停止、RAM上限950MiB。outputが既存なら上書きしない。126照会は旧62+追加32+未知32という検証件数であり、126独立経験ではない。初期fixtureは主公開録画の6像。索引/問題番号/ファイル名はruntimeに渡さない。

予測比較では固定型.pyの予測記録契約に従い、結果経路と条件値群の外側列だけを正規化する。全条件要素と予測値の内部型/値を厳密比較し、支持前提を比較から外さない。

## 失敗由来と移植差分

旧証拠は別の凍結研究資料で保持している。初版は生HDS結果経路tupleと保存listを比較して偽HOLD、次版は条件値群の外側形式差を退行と誤判定した。条件値群を射影から外す案は中止し、全条件を含む型契約比較へ修正した。Action/不正予測/例外/未説明画素/準備選択/資源上限は独立監査で補強した。

この移植のruntime差分は関節線因子の相対importだけ。因子ファイルは旧凍結とbyte一致。試験コードはscratch固定pathと旧helper script読込みを除き、portable fixture・外部state env・自己完結の意味SHAへ置換した。旧75ファイル、main、core、dispatcherは変更していない。

## 統合試験の資源境界

この資源検証helperはLinuxの `/proc/self/status` のVmHWM（exec後のアドレス空間の最大RSS）をkBで読み、950MiBを超えると停止する。取得不能/形式不明も失敗にし、上限確認を省略しない。他OSでの同等計測は未実装。runtime APIの依存ではない。

親の統合回帰で先行試験が3GiB以上を使用すると、旧ru_maxrss判定は後続の軽量試験も950MiB超過と誤検出した。新規subprocessだけではfork/exec由来の高水位が残る実反例も確認した。元2失敗を保持し、試験を直列の独立過程に分けたうえで、現在のアドレス空間のVmHWMを検査する。1GiBの親からの起動・実/反証/空・上限超過・計測不明を別に検証する。学習/候補/採否の処理と元950MiB上限は変更しない。
