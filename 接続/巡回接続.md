# 巡回規則 独立接続候補

main 14721d の186ファイルへ追加する独立接続。既存共通dispatcherへの登録は行わず、現在HDSを明示注入する。

## APIと適用境界

`接続.巡回規則.候補を構成する(系, 盤面, *, 作用可能番号, 出所=None, 検証状態上限=100)` と `観測から候補を構成する(系, 現在, *, 検証状態上限=100)`。既存公開観測と同一の現在 HDS インスタンスを渡す。毎回その系を実照会する。runtime の接続コードに教材パス、録画読込、教師索引、game/level/hash の解法分岐、固定行動列はない。出所は返却用だけ。非進行状態は提案せず、WIN だけ公式完了確認を返す。

固定64×64画素知覚・全変位文法・巡回探索と、HDSによる候補採否を分離。標識の四隅と中央色、等間隔直線、全対象が一つの単純閉路となる図形だけを対象とする。各矢印の全 k と実入力/原照会/支持・不支持・HOLD・例外を保存する。反証状態/空状態では支持がなくなり計画は HOLD。単純な途中状態も同じ関係で検査し、初期だけの記録lookupにはしない。

操作標識は実画素マスクを照合。中央token・四隅・矢印の実画素を被覆し、黄色背景矩形の穴/未知画素や矩形外の役割不明画素を照会前HOLDにする。上3行と左端1列は既存UI領域として知覚対象外。このUI領域の意味は本語彙では検査しない。

全到達状態・全作用辺・全goal・全最短親を返す。未知作用は捨てずHOLD、availableの6以外も未評価として返す。作用例外時は部分graphと未評価辺/frontierを保持して全体HOLD。候補の一部を落とした成功にはしない。限定モデル内で成立する計画と外部実行許可を分離し、実行許可は常にfalse。

同一巡回順または対象が互いに独立な巡回列では、色周期の積から到達数を正確に算定する。列が重なる場合は未学習の合成境界としてHOLD。既定100状態は公開小対照で検証した計算資源上限であり、学習した不可能条件ではない。外部引数で明示変更でき、超過時は算定数/既知モデル全件/初期frontierを保持して全体HOLD。上限を増やす呼出し側が資源を予約する。

可視目標充足は NOT_FINISHED のままでも成立する。空の初手を達成不能と混同せず、観測目標充足と公式WINを別フィールドにする。すべての計画は未知作用HOLDを含む限定範囲で、全ゲーム解閉包やfresh成功ではない。

## 学習再現と回帰

採用する公開教師は全94入力。旧74に、10独立Action由来の20入力を追加したもの。原票Action×同一HDS入力を集約し、同じ観測の候補展開で支持を水増ししない。全94は80原票行相を参照するため94独立実観測とは数えない。旧190重複対照・旧候補・保存失敗は実験履歴に保持。

教示はruntime候補APIと分離し、検証/巡回教示/巡回公開教師を教示.py を明示的に起動する。全94原入力、原票SHA、既定文脈、4事前照会順は隣接gzipに格納する。通常HDSで学習・保存・再読込し、具体1576記録時刻leafだけ比較用copyで元時刻へ戻した全構造SHAで確認する。元保存byte一致は主張しない。記録時刻は現行coreの推論条件として参照されない。任意の同名辞書キーは除外しない。

REPOをこのrepositoryの絶対pathとして:

```sh
export PYTHONDONTWRITEBYTECODE=1
export PYTHONPATH="$REPO:$REPO/HDS/学習系統/v0.4.2"
python -B "$REPO/検証/巡回教示/巡回公開教師を教示.py" --output /tmp/新規巡回94.json
export ARC_LOOP_TRAINED_HDS=/tmp/新規巡回94.json
# ARC_LOOP_CONTRADICTION_HDSには独立検証済み人工反証95のgzipを明示指定する。
python -B -m unittest discover -s "$REPO/検証" -v
```

実94/反証95指定がない試験はskipを明示する。親検証では両stateを明示し省略なく実行。保存gateの契約と失敗証拠保持は検証/巡回教示/README.mdを参照。
