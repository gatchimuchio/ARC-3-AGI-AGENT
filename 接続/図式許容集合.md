# 公開成功答えが支持する条件付き許容集合

既存の指示参照が要求する色と、参照がない対象の許容色を区別する。三つの公開成功完成を30対象へ集約し、同じ外部HDSへ30経験を追加する。学習結果は「指示参照なし → 観測された成功完成で色列全色が支持された」という有限対応。全問題で自由な色を選べる一般則ではない。

適用範囲は観測二色、単一の指示格子、未参照かつ標識なし本体、HDSが支持した自己対象だけの作用。25ゲーム183初期観測の構造確認では、元の問題以外に同型候補を確認できなかった。3成功は同一の可視問題であり、新しい問題への転用証拠はない。

`許容集合を含む図式攻略を照会する(盤面, 利用可能作用, 学習系, 適用支持)` は公開問題だけを受け取る。既存の複合図式照会を再利用し、未拘束対象の個別保留を支持された許容集合へ置き換える。既存の他の保留とHDSの全体隔離を残す。空集合、未支持色数・装飾・連動役割、作用不可、部分照会のHOLDは計画完成にしない。

二色の有限制約解法・操作の可換性・標識保存は既存の固定モデル仮説。作用の次色関係・連動関係・解答役割と追加の許容役割は同じHDSの公開照会に従う。完成答えや作用列をruntimeから参照しない。

## 成立した範囲

同じ問題から21手と22手の条件付き整合経路を構成し、どちらも30対象の目標集合を満たす。前者は二つの公開完成、後者はもう一つの公開完成と全本体が一致する。共通入口は両経路を別々に保持し、各先頭を次作用の代替候補として返す。経路を連結したり、一つを無根拠に選んだりしない。各手で再観測が必要。実行許可は常にFalseで、fresh実行成功は未確認。

単体試験は基底教師の小さい境界fixtureを使う。全経験の検証は次のCLIで再現する。

```
python 道具/図式許容集合教師検証.py \
  --基底教師 検証/資料/複合図式公開教師.json \
  --追加教師 検証/資料/図式許容集合教師.json \
  --照合資料 検証/資料/図式許容集合照合.json \
  --出力 /tmp/許容集合検証
```

既存818経験を処理後、同一状態へ30経験を追加する。既存の保存状態を再利用する場合だけ `--基底状態 PATH` を指定する。入力状態SHA、教師台帳、追加前/後の照会、全候補経路、全画素残差、実学習状態と照会後状態を出力する。原票URL/digest/行はfixtureの出所に含まれ、完成盤面はCLI末尾の評価だけで読む。

標準回帰: `python -m unittest discover -s 検証 -p 'test_*.py' -v`。
