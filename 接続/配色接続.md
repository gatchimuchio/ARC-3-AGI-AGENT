# 器具配色の条件付き目標と作用

現在の公開画素、利用可能作用、呼出側の同一 HDS v0.4.2 を受ける独立入口です。共通入口と core は変更しません。実行許可は常に False です。

## 確認された範囲

隔離実験の最終三値履歴監査では、全 2253 応答相を保持し、449 作用で継続成立、185 を HOLD としました。履歴を連鎖伝播した意味予測は 564 一致、70 未支持、不一致 0 です。履歴を独立に与える単段照合の 605 一致とは条件が違います。固定黒修正後の単段支持終端 619 相は全画素一致 222、最下行だけ残差 397 でした。最下行以外の一致を全画素一致とは呼びません。

全 23 経路・351 段は同じ学習状態の条件付きモデル内の目標一致です。実応答の animation をすべて通過する経路ではなく、未知相で必ず止まります。

## 学習した関係と固定の計算

公開成功 2 資料と未完了 1 資料の問題・完成・実作用から、参照色と候補色の一致関係、現在方向と方向作用から後方向、幾何領域候補と可視上書き、3 つの受理候補視点と実進捗を同じ HDS に教えています。初期 813 教師を保存した後、全公開資料の 735 教師を追加した計 1548 入力です。提示順を変更しても同じ結果になるとは証明していません。

10×10 正方形、黄の見本枠・色見本、赤枠器具、12 の器具姿勢形状、固定黒の区別、半平面・小矩形の幾何、上書き依存の逆向き全幅探索は固定知覚・合成文法です。HDS がこれらを発明したとは扱いません。固定文法は原票の役割形状に由来し、現在器具の全役割画素がその12配置に一致することを照会前に検査します。runtime は教師原票、完成答え、保存 action 列、問題 ID を読みません。

## 目標と全候補

色対応規則から同位置の全色一致を代表目標として構成します。14 完成中 12 は 100/100、2 は 95/100 で受理されました。失敗側に 90/100 があるため、単調な一致数閾値を仮定すると 91〜95 が候補です。単調性自体は未確認です。短い対角差分、かつ見本色境界上という別の説明も保持します。他の位置・色・層の条件は排除していません。

短対角変更の全条件付き候補と全保留候補を保存します。この有限文法以外の画像を棄却しません。代表目標の全最短塗布列 23 経路、351 段を保持します。方向移動は各区間の代表証人であり、全作用列の最短性・全ナビゲーション経路の網羅ではありません。代替受理目標への到達性は未検証です。

全 SDK クリック 4096 座標を保持します。既観測の役割・矩形寸法・相対クリック位置に範囲を限定し、未観測の矩形内座標も HOLD とします。相対位置の転用自体は固定の知覚仮説です。生記録で未対応だった 26 クリックを無作用扱いしません。3 非 frame 記録も別途保持します。

## 継続境界

配色全応答を照合 は raw 前後応答と実作用を受け、応答 action_input の番号・x/y、前後状態、進捗カウンタ、RESET、実行 GUID、観測順序を確認します。現在の外部 HDS へ毎回再照会し、古い予測だけで後続を許可しません。

全 frame を保存し、途中相を捨てません。各相が前盤面または予測盤面に一致しない場合、知覚不能・新構造の場合は HOLD とし、次履歴を渡しません。既知 animation として無条件許容する文法はありません。RESET・進捗では旧履歴を証拠に残し、新履歴は空です。履歴は有・無・未確認の三値です。斜め姿勢で小器具が見えないとき、未確認を不在に置き換えません。次に有無が直接可視となる場合に再取得できます。未知の有無で次配置が分岐する作用は HOLD です。

最下行は表示領域候補として対象外差分を全座標保存します。表示の意味や更新則の学習はまだありません。この行の作用を予測していないため、最下行以外の一致を全画素一致と呼びません。351 段もこの条件付き描画モデル内の再知覚・目標充足であり、実 API の新規成功を示しません。

旧実験では固定黒 2 画素を色役割へ縮約し、185 作用・187 相に残差がありました。また未知中間相が継続を止めませんでした。失敗成果を外部の隔離実験に保持し、本候補では修正しています。修正により継続成立件数が減ることを性能改善に読み替えません。

## 空経路の評価境界

CLI は全代表経路が非空であることと各モデル終端の目標一致を同時に要求します。空 HDS、人工反証、解法例外から経路が出ないときは「未成立/HOLD」で、全称判定の空集合を成功として表示しません。旧初回候補の all(empty) 誤表示は別フォルダの失敗証拠として保持しています。

## 再現

保存済み実状態を再利用：

    python -m 接続.配色教師CLI --出力 /tmp/配色検証.json

全原票の継続境界を含める場合は --全原票 を付けます。全再学習は明示的な --全再学習 --状態出力 /tmp/配色状態.json.gz が必要です。各入力と途中 checkpoint を保存し、保存無書出・破損・例外は失敗として止めます。gzip は core の外側で可逆圧縮し、復号 SHA を検証します。

教師 fixture と runtime は分離しています。入力/配色教師 に全入力順、出所付き全原票、問題/完成候補、実状態を置き、教師 CLI だけが読みます。完成画素は推論後の評価にのみ利用します。授業内再構成であり、未知ゲームへの転用成功は未実証です。
