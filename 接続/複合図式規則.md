# 公開問題・解答・作用から学ぶ複合図式規則

## 可能になったこと

公開盤面の二色・小図格子・標識付きセルを構造で認識し、同じ HDS に教えた解答関係、色作用、隣接連動を照会する。対応した盤面では、全目標制約を満たす条件付き作用候補を組み立てる。推論 API は盤面・利用可能作用・注入された HDS・教師由来の適用支持だけを受け取り、ゲーム名、問題行、完成答えを受け取らない。

実行権限は常に false。現段階は候補と公的人間実演との照合であり、自律 fresh 成功は未実施。

## HDS が学ぶ関係

- 小図の記号役割 → 周辺の解答対象が中心色と一致/非一致、または観測成功実演で直接配色を割り当てなかった参照
- 現在色が観測色列の末尾か → 次隣接色/先頭色
- 隣接方向の辺中央に標識があるか → その隣接本体色が変わるか

固定文法は小図/本体/標識の知覚、格子の直交関係、色列の隣接/先頭操作、二値制約消去。これらの演算器自体を HDS の発見と呼ばない。標識保持、二色効果の可換性、モデル適用文脈の安定は条件付き仮説である。

## 教師と評価

同梱の `検証/資料/複合図式公開教師.json` は検証済み公開原票から抽出した 818 経験と出所を持つ。内訳は解答130、色作用164、連動524。各経験を通常の `処理する` に順番どおり投入する。

解答は最初の完成見本と L5 の完成答え/成功実演から教える。色作用と連動は L5 の全試行から対応できる観測を教える。L6 は開発評価であり、未見最終試験ではない。3 人の実演が同じ問題配置を共有するので、3 つの新しい問題への汎化とは数えない。

L5 の成功実演は A:160→185、B:284→341、C:106→137。未完了区間 B:222→265、266→283、C:72→105 と RESET 3 行も保存した。直接操作省略は「この成功実演では直接編集しなかった」という存在証拠であり、hidden 無影響、永久的不要、操作不能という一般則ではない。

出所は公式公開人間データ https://arcprize.org/blog/arc-agi-3-human-dataset 。同梱教師に3原票の直接 URL と SHA256、各教師の行と対象を記載した。ID は原票の索引だけに使う。

## HOLD と候補集合

適用可能・構造上不適用・未確認を分離する。解析例外や教師支持不足を不適用へ隠さない。未知の標識色、角/部分標識、格子/対象対応不明、未拘束対象、HDS 隔離、利用可能作用不明は保留する。既知の L5 には未拘束セルがあり、この入口は全体を保留する。

複数の整合した操作偶奇解は特解と同次解基底で欠落なく保持する。規則の不確実性とは別項目である。複数解時の代表選択は未実装で、候補を捨てず後段へ返す。唯一解時の座標順は可換モデル内の順序代表であり、解答 lookup ではない。

単一の HDS に矛盾を投入すると、解答・色作用・連動の照会すべてが保留する。隔離範囲を勝手に狭める処理はない。既存 L2–L4 接続は変更せず、装飾付き二色という限定構造を追加した。

## 再現

リポジトリ直下から:

```sh
PYTHONPATH=.:HDS/学習系統/v0.4.2 python -m unittest discover -s 検証 -v
python 道具/複合図式教師検証.py \
  --教師 検証/資料/複合図式公開教師.json \
  --問題 検証/資料/複合図式照合盤面.json \
  --出力 /tmp/複合図式検証
```

全103対応作用の原票再照合は、教師JSON記載のURLから取得し SHA を照合した3原票を `<実行識別子>.recording.jsonl` として置き、上記へ `--原票ディレクトリ <保存先>` を追加する。認証情報や SDK API キーは使わない。複数frameの応答はこの限定作用照合では保留し、最初と末尾を同一視しない。

教師台帳、学習状態、空学習機械対照、候補、完成後照合、原票指定時の全作用照合を出力する。完成答えを教師/候補生成へ流入させない。失敗した88教師の構造不変解釈、76教師の3HOLD、独立セル作用モデルの反証は採用ロジックから除き、履歴と出所説明に残している。
