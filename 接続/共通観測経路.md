# 共通の公開観測照会

`公開観測から候補を照会する(学習系, 現在, 図式適用支持=...)` に、既存 `ARC3境界.観測` と同一の外部 HDS を渡す。列展開と複合配色を双方照会し、ゲーム ID・レベル番号による解法選択はしない。教師取り込みは既存の `道具/列図式教師検証.py` と `道具/複合図式教師検証.py` を使う。新しい学習機械や作用実行器は作らない。

構造上不適用、解析未確認、構造上適用可能を分離する。同一 HDS の隔離は全体へ保持する。構造解釈が複数ある場合は優先順位で選ばない。目標候補、元の作用候補、不採用理由を保持する。複数の整合解は規則の矛盾とは別記録になる。

列展開の作用候補は現在の代替候補群、複合配色の作用候補列は順序付き経路である。後者は全経路を保持しつつ、先頭だけを次作用候補へ射影する。後続の作用は新しい公開観測で再照会が必要。全出力の実行許可は False。環境 step や HDS の確定作用 API は呼ばない。

## 複数 frame の応答

`作用応答を相別に記録する(直前, 現在, 作用番号)` は一回の作用選択と全応答 frame を保持する。直前の最新盤面から先頭応答への差分、応答内の隣接相差分、次計画用の末尾盤面を別記録する。

先頭は単に最初に受け取った観測であり、作用の原始効果や完成相とは断定しない。完了数増分がある場合も全相を旧目標照合候補へ残す。現段階では旧問題の構造・目標との自動照合は未実装で、完成相採否は常に未確認。内部アニメーションや問題切替との境界も未同定。候補が一相だけでも完了増分だけを根拠に採用しない。最新同士の差分を旧問題の作用因果へ使用しない。

実例では公開列展開記録の一回の作用に 118 frame、公開複合配色記録の一回の作用に 2 frame がある。両者で固定 index の意味を共有する仮定は置かない。GUID/ゲーム境界、初期化、順序、可用作用、欠損を確認できない場合は差分の作用対応を保留し、生の応答を保持する。

## 再現と範囲

`PYTHONPATH=.:HDS/学習系統/v0.4.2 python -m unittest discover -s 検証 -v`

共通入口の回帰は `検証/test_共通観測経路.py`。既存各語彙の教師 pack、出所 URL、原票 digest と学習コマンドは各語彙の説明に従う。図式適用支持も教師 pack に由来し、runtime で答えを読み込まない。

この追加は学習済み規則の照会を共通化した候補専用の入口。25 ゲーム全語彙、完成相の自動同定、環境への作用送信、新規実行での成功は未実証。

## 四語彙の同一状態接続

列展開・複合配色に、根付き順序鎖と形状目標対応を加える。ゲーム識別子による
振り分けは行わず、同じ公開盤面を各固定知覚文法へ渡す。学習済みの同じ HDS を
引数で受け取り、各語彙の目標・作用関係を照会する。入口で別の学習系は作らない。
本変更は既存の学習済み関係の接続であり、新しい規則を学習したという主張ではない。

### 目標と作用の範囲

`適用性` は目標の可視構造、`作用適用性` は既存作用モデルの必要前提を表す。
形状の目標対応は複数の輪郭・対象を照会できるが、現在の占有・移動モデルは
二つの青い 3×3 対象、二つの可視閉輪郭、一意の選択標識に限定される。
作用の範囲外でも、目標対応・全割当・局所保留を削除しない。
目標の未観測部分、結合/分解未同定、解析例外は `未確認` とする。

列文法は、既存の四隅標識付き起点を必要とする。容器外形の同じ純粋検査を共用し、
起点が一つもない場合だけ必要構造の不在とする。複数起点・背景同数・記号解析例外は
引き続き未確認とし、解けないことを不適用の根拠にはしない。

### 経路と次作用

新しい `作用段階経路群` は、支持経路と未支持経路の両方を保持する。
各段階は `作用候補群` を持つ。対象内の同値クリック座標は代表一点へ縮めない。
全段階の支持と目標照合が成立した経路だけ、その先頭段階を現在の次作用候補とする。
後続段階は再観測後に照会し直す。別経路が同じ先頭作用を支持していても元の記録は
残すため、次作用レコード数は異なる作用の種類数とは限らない。

局所的な未支持辺・対象外座標は、各語彙の原結果と保留理由へ残す。
同一 HDS の公開 `係争中原理群` は全体の保留として保持し、語彙ごとに隔離を狭めない。
構造が未確認の別語彙も黙って無視しない。

### 検証と未実行範囲

基底 2286 経験は、列 78 + 複合 848 + 鎖 997 + 形状 363 の順次実学習状態である。
元状態と入力・文脈・出典の組を保持して使う。HDS 経験の既存 schema 自体には文脈欄がない。

対象回帰は、リポジトリ直下から次で実行できる。

```sh
PYTHONDONTWRITEBYTECODE=1 python -m unittest \
  検証.test_追加語彙接続 検証.test_共通観測経路 -v
```

列原票の回帰は既存 `検証/test_列図式規則.py` に `ARC_PUBLIC_TEACHER` と
`ARC_PUBLIC_SHA256` を渡す。公開原票・SHA は `接続/列図式規則.md` を参照する。
追加試験は、同じ HDS の注入、目標/作用範囲、tuple 行の明示正規化、局所保留の共存、
全同値座標、後段未支持、解析例外、起点なし/複数の区別を検査する。

実環境の step は送らず、`実行許可` は常に false。
新しい二語彙の完成相同定・実測差分との専用照合は、この変更には含まない。
既存の全応答 frame 記録を維持するが、列/複合用の完成相照合を鎖/形状へ流用しない。
既知の公開教師で成立する条件付き経路を、fresh instance の成功とは扱わない。
