# 公開根付き順序鎖の独立接続

## 入口
`接続.鎖接続.鎖候補を作る(frame, available_actions, hds, *, 経路も作る=True, 照会共有=False)`

公開画素・作用領域・外部注入された同一HDSだけを受け取る。ゲーム名、レベル、記録、答え作用列を推論入口に渡さない。共通入口は変更せず、この接続だけを追加する。HDS中核・権限・既存記憶を変更しない。学習と照会は公開APIのみ。

正本出力は「適用性、対象群、関係群、目標候補群、作用候補群、保留理由群、照会記録、出所、実行許可」。経路候補群、作用照合群、探索記録を追加する。未知・知覚例外・隔離は未確認/断定保留で保持し、構造上不適用に偽装しない。実行許可は常にfalse、採用順序も空である。

## 全経路採否の修正
初期問題の格子モデルには最短14手の経路が20本ある。全280段を32固有状態作用へ照合すると、旧局所規則も全段支持するのは11本。残る9本は未知の局所前提 `次要求不一致/間隔19/押し空間なし/他根拘束false` を含む。状態1→6 ACTION4と状態4→10 ACTION4の2辺が該当する。

この9本を消さず「断定保留」、11本を「両規則支持」に区分する。未知は予測不一致ではない。全経路を判定し、最初の成功経路だけを採用しない。表示14手の教師再構成は維持される。全20経路は格子モデル内の候補、実環境成功や全経路安全の証拠ではない。

## 学習/固定/未対応の区分
- HDSが取得する内容: 既存960経験による目標根/順序と局所作用、および37関係教師による根・腕・珠の「不変/作用方向一格」。合計997経験を同一状態へ順番通り入力。
- 原観測: 追加37教師は214公開作用・1247個体観測の集約。関係教材内に重複を含む全支持行参照を保持。実入力数と原観測数を混同しない。
- 固定処理: 画素分節、凡例/根/珠/線、6画素格子、付着/占有依存閉包、変位語彙、条件の組、候補領域、描画、状態等値、全幅BFS、列変化と局所ラベルの整合検査。これらをHDSの自由発見とは主張しない。
- 次状態適用範囲: 単根、右軸、矩形無障害、一意色珠。公開2教材214作用で再構成済み。多根/共有/障害物/逆軸等の残る730作用を解いたとはしない。

全4101候補（4方向、64×64クリック、ACTION7）を保持する。座標同士で格子関係が同じ場合は群参照で表現するが、全座標を共通候補領域から追跡できる。未支持辺957と未展開前線330を保持。BFSは最短目標層直前を全展開して停止し、長い経路は未検証であり失敗ではない。最短性は支持済み可視格子モデル内に限る。隠れ状態・時間・未観測配置での外挿は未検証。

## 再現
このrepository以外の研究ディレクトリや公開ネットワークは不要。

```bash
PYTHONDONTWRITEBYTECODE=1 python -m 接続.鎖教師CLI --共有照会 --出力 /tmp/鎖候補.json --保存状態 /tmp/鎖997状態.json
PYTHONDONTWRITEBYTECODE=1 python -m unittest discover -s 検証 -p 'test_鎖接続.py' -v
```

CLIは公開fixtureを空HDSへ教師入力し、実HDS状態を任意pathに保存する。予測答えの辞書や固定作用列は学習状態に代用しない。frameは教材の初期観測だけを推論へ渡し、214対の前後原画素は試験時の再構成照合にだけ用いる。

照会共有は明示指定。HDSの意味状態が固定され、途中に学習や外部変更を挟まない寿命でのみ利用可能。直列対共有の4101全候補、旧960/932、格子214、空/反証/例外、Memory意味と根拠の一致は前段隔離監査で確認。照会連番は履歴として保持され、共有は各候補の原照会参照で追跡する。並行更新されるHDSへの共有は未承認。
