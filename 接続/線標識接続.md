# 線標識の独立接続

外部HDSを注入し、公開問題から学んだ線・標識の関係を照会して全解法候補を構成する。共通観測経路・自動実行には未接続。

## 入力と出力

`線標識候補を作る(問題, 利用可能作用, hds)`。
問題は64×64整数画素、利用可能作用は外部環境の作用番号一覧、hdsは呼出側が保持する同一HDS。入力は問題のみで、ゲーム/レベルID、完成答え、予定行動列を受け取らない。runtimeは公開教材や実験ディレクトリを読まない。継続盤面を初期と読み替える運転には未対応。

固定知覚は既存「図式観測」の4連結成分を使用し、3×3黄環、標識中心色、黒い選択中心、線形状、前後描画を分離する。幾何文法の分岐は画素由来の二色十字/三色図形。二図形は全最短経路列、三図形は共有DAGで全最短親・全五作用候補・現在/一歩周辺の全再分解を保持する。教師削除・条件境界変更・HDS隔離解除は行わない。

全照会は同じ注入HDSへ行う。照会途中で例外が起きた場合は、それまでの照会・例外を残して全体保留。空state、競合state、未知前提、観測分解非一意も保留。実行許可は常にfalse。外部未学習作用も保留として保持する。候補のHDS規則支持と、合成した画素の再観測支持は別の条件。

## 公開教材と再現

`記憶/公開教材/線標識.json.gz` は2143全教師、元教師通番、同一境界、出典、二つの初期問題、原票hash、外部state復号hashを可逆圧縮した教材。原票IDは教材の出典にのみ用い、runtimeの答え条件に使わない。完成答えは教材に含めない。凍結実stateを同梱複製せず、外部指定する。新規学習は不要。

テスト:

```sh
RE86_TEST_HDS=/path/to/交互学習状態_2143.json.gz PYTHONDONTWRITEBYTECODE=1 python -m unittest discover -s 検証 -p 'test_線標識接続.py'
```

問題JSONは64×64配列だけをファイルへ保存する。CLI:

```sh
python -m 接続.線標識教師CLI --状態 /path/to/state.json.gz --状態SHA d7bbfca081470e83cd116425dafefc1b5a45c91f69ff991d35199b99e1d79e52 --問題 /path/to/problem.json --出力 /new/path/result.json.gz
```

CLIは全候補を可逆gzip保存する。既存出力を上書きせず、復号検査後に排他的atomic linkで確定する。保存失敗は例外として呼出元へ返し成功にしない。既存stateへの書込はなく、復号用一時ファイルは処理後に消える。RAM Available 2.4GB未満、復号用disk600MiB未満なら読込開始を保留する。

## 再現結果と限界

同じ2143学習stateで、二図形20操作・9240経路、三図形36操作・9,513,504経路。三図形の2,979,900は条件付き支持、6,533,604は観測HOLDとして保持し、最短親10辺がHOLD。第一問の非最短一歩周辺1候補も、凍結第五段の追加採否と同じ選択中心/標識重合HOLDを構成器に反映した。

この数字は全ゲーム攻略や実環境成功ではない。第3問以降の同色個体・中心履歴・後期色枠/尺度は未対応。二図形426,888、三図形295,833,384の全因子積画素は未検証。検証したのは全最短分岐61/117と現在・一歩周辺166/312。公開完成答えとの中心配置後照合は研究で実施したが、完成全画素は未照合。

原順の同じ2143教師は全体HOLDになった。別の空HDSへの全候補早期交互提示による支持成立は提示順比較であり、原順状態の修復・一般学習順序への頑健性を意味しない。静的中心構造は第3問の公開反例で競合し全体HOLDになるため、文法の無断拡張や中核修正で回避しない。

## 入口作用契約の修正履歴

初回候補は重複・範囲外作用を許し、同じ実HDSで12照会後に条件付き支持となった。独立監査の3反例（重複5、-1、8）を保持し、既存列図式/共通入口と同じ整数0〜7・重複なしへ合わせた。r2は照会前に全体HOLDし、不正作用も未評価候補として記録する。合法だが未学習の0/6/7は従来どおり保留で残す。初期観測であることを画素だけから証明する機能はない。初期専用という適用条件の下でのみ使い、継続制御へ自動採用しない。

第1問の初回候補は対象/標識以外の画素を見落とし、背景(0,0)へ未知色2を置いても支持した。旧失敗を残し、r3では既存描画器の全2順と上63行の完全比較を照会前に要求する。一致する描画順が存在しても、HDSが支持した順と異なれば保留する。最下行HUDの予測は未対応で原観測に保持し、全64行一致とは呼ばない。
