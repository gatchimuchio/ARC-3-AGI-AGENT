# 字形解法・初回作用・応答継続の追加接続

外部から同じ `HDS学習系統` を注入する。runtimeでHDSを生成せず、教師、完成答え、録画、ゲーム別辞書を読まない。共通入口、凍結core、権限文書を変更しない。

## 単体API

- `初回作用を構成する(系, frame, available_actions)`：承認済みの全目標/全有限グラフ/全初回作用を保持し、一つの条件付き証人を提示。
- `字形初回を照会する(学習系, 現在)`：既存 `ARC3境界.観測` を受け、前回照会との対応に必要な観測通番/指紋と実選択・実字形履歴を付ける。
- `字形作用応答を照合する(学習系, 直前, 現在, 前回照会, 作用番号)`：前回予測を応答全相へ照合。一致しても旧手順の残りを無条件に実行せず、現在観測から同じHDSへ再照会する。

全APIは `実行許可=False`。外部stepは呼ばない。runtimeが返す初回候補と、継続可否は別の判断である。

## 継続条件

既存909応答の知覚分類を再利用し、旧問題の固定内容/欄配置を相ごとに比較する。実選択欄、全欄の予測族、非対象実字形の保存を照合し、対象欄の実字形は族と別に記録する。全相は既存 `作用応答を相別に記録する` でも保持。

RESET、全初期化、別公開instance、完了数減少、進捗/終端では旧手順と選択履歴を分離。公開ID/指紋は対応の検査のみで、解法や目標の選択に使わない。可視字形/選択枠の再訪をhidden同一性とはみなさない。

予測不一致、選択非一意、相混在、未支持HDSは後続手順HOLD。旧目標、作用、全関係グラフを削除しない。HDSのglobal HOLDを別HDSへ分割して回避しない。進捗応答でも旧目標族と実測増分を別記録し、未達を提出失敗や無効Actionに読み替えない。

現在の選択欄から全目標への継続可能性と固定証人提示を分離。固定BFS/既達欄維持順はHDSが学習した選好ではない。ACTION5/6/7/RESETの未支持領域も保持し、ACTION6の未評価座標領域を落とさない。

## 学習と固定演算

公開HDSが学ぶのは見本対の所属同値、編集役割、族作用、カーソル関係、応答達成関係、選択/非選択欄の族変化。7×7知覚・D4同一視・群分解・グラフ/変数制約・手順提示・全相照合は固定演算。

研究用の英語辞書項目を内部日本語に移した。単なるPython識別子は不要に改名していない。SDK生観測内の英語キー、Action記号、HDS公開契約は外部契約として保持。

## 実状態を使う検証（再学習不要）

`d8a50812c89cacf62edf088c0e9bf81bf93f32823df3c269cecec5b373511275`

1. `python 道具/字形教示検証.py --状態 <承認済みstateのpath>`：保存SHAと54照会を検査。
2. `ARC_GLYPH_HDS_STATE=<同path> PYTHONDONTWRITEBYTECODE=1 python -m unittest discover -s 検証 -v`：保存済み全目標/証人、空HDS、反証global HOLD、実応答、全相、予測/選択不一致、RESET境界、履歴継続を検査。

state未指定なら追加の実状態統合試験を明示skipする。既存main回帰と空HDS/依存検査は実施。実状態を使う試験を通ったことと、skipしたことを混同しない。

教師は `検証/資料/字形/全1992教師.json`。既存391＋作用保存1601、境界/内容/順序不変。全量再教示が必要な場合だけ `python 道具/字形教示検証.py --方式 全量教示 --出力先 <未作成dir>`。単一HDSへ全件投入し、入力/結果を追記flush、391/791/1191/1591/1992件で実状態を保存、例外時も保存を試みる。最小支持数を合わせるための抜粋・反復はしない。

公開資料は設計閲覧済みの教師/開発観測。六問題の全目標数は1/1/1/1/2/420。全候補を保持すること、条件付き経路を提示すること、実際に成功することを区別する。新規実環境作用0。

## raw盤面の外部契約guard

`初回作用を構成する` はHDS照会・字形知覚より前に既存ARC3境界の `_盤面列((frame,))` を使う。最大64×64、矩形、空行なし、厳密整数0..15を検査しtupleへ正規化する。違反は未確認/HOLD・HDS照会0。1–4も含む全合法available_actionsを未評価領域として保持し、ACTION6の全座標集合を無効盤面の寸法で限定しない。
