# 公開見本から解答配置を学ぶ接続（未統合）

## 教えるもの

固定の知覚文法で、3×3の小図と、その周囲に拡大配置された8セルを対応付ける。完成見本から「小図の指示記号順位 → 周辺の解答セルが中心色と一致するか」を、通常の HDS 処理する API に教える。白/灰の極性、解答配置、クリック順序はプログラムに埋め込まない。

HDS が学んだ対応を別の問題の小図へ照会し、重複セルの制約を交差させ、現在配置との相違からクリック対象を生成する。ID・絶対座標・解答盤面は照会条件に含めない。座標は検出セルから実行直前に導出する。

## 固定仮定と境界

- 3×3小図、単色小ブロック、拡大配置の幾何対応は固定知覚文法であり、HDSの発見ではない。
- 記号は小図内の色番号順で正規化する。任意の色置換への不変性を主張しない。
- 背景から区別された強調パネルがある場合に非強調側を完成見本候補とする。一般の役割同定ではない。
- 利用色は画面端に接する同寸法の単色正方形列を見本とする仮説。作用による色cycleの閉包は未検証。
- 未被覆小図、部分/異スケール重複、複数色候補、HDSのHOLDを残す。全体がHOLDならクリック対象を採用しない。
- クリック対象は色変更要求であり、1クリックで必ず要求色になることやfresh成功を保証しない。実作用後に再観測・再照会する必要がある。現実行許可は常にFalse。
- 公開APIに一括lesson入力はない。listを渡しても独立経験群にならない。通常の逐次入力を使い、HOLD/隔離の回避はしない。

## 再現例

公式公開原票:
https://arcprize.org/api/recordings/ft09-0d8bbf25/01f76fc7-c612-4006-8d08-c13ed0cb91de

SHA256: a5801fb3b98f76fcea76fe359a957a6197cf5e88a02098c4df5a020c2c43bd29

取得済み原票を置き、リポジトリ直下で実行する。出力先は新しいディレクトリを指定する。

```sh
python 道具/図式解答検証.py \
  --source /path/to/01f76fc7-c612-4006-8d08-c13ed0cb91de.recording.jsonl \
  --sha256 a5801fb3b98f76fcea76fe359a957a6197cf5e88a02098c4df5a020c2c43bd29 \
  --teacher-row 0 --problem-row 94 --answer-row 106 --output /path/to/new-output
PYTHONPATH=. python -m unittest discover -s 検証 -v
```

行番号は原票の教師/評価範囲を指定するだけで、実行時の解法分岐には使わない。問題frameは当該行の末尾、解答frameは成功遷移行の先頭。全原票のSHAを検証する。

## 確認結果と限界

L1の完成見本3個・24セルから、指示記号順位0→中心色一致、1→非一致という有効な暫定原理が成立した。原理採用時の支持参照は経験1〜3で、全24経験は記憶・監査された。24を採用時支持数と読み替えない。

同じ学習状態の比較:
- L2: 16制約、重複統合後13セル。公式完成frameと13/13一致、7クリック対象。空HDSは13セル全HOLD、クリック対象0。
- L3: 32制約、23セルが23/23一致、14クリック対象。
- L4: 当初の色候補不足では完成答えと2セル不一致・4セルHOLD。公開色列を加えた後は11セル一致、7セル複数候補HOLD。全体HOLDでクリック0。完成答えとの不一致だけでは別解不正を証明しない。
- L5: この文法で8セルのみ照合できたが、他小図を覆えず全体HOLD。
- L6: この文法では解答配置を構成できずHOLD。

完成答えは学習へ入れていないが、L2〜L6は設計時に閲覧済みの開発評価。最終未見評価でもfresh実行成績でもない。25ゲーム/183レベル全体を解けたとは主張しない。

## 保持/変更と作用効果の合成

追加の教師と条件付き結果:
- L1初期→完成から32セルの保持/変更を測定。同じHDSの公開境界で「現在の全解答制約を満たす→保持、満たさない→変更」を学習した。
- 2つのL2公開episodeの実クリック26件から「色列末尾でない→次隣接色、末尾→先頭色」を学習した。修正クリック6件も含む。幾何的な色列順序と隣接/先頭の演算は固定文法で、どの演算を適用するかがHDS由来。
- 最初のL2だけでは末尾条件の教師がなく、現行HDSは原理を採用しなかった。この負の結果を保持する。
- L4で保持7/変更11、16クリック分の条件付き経路を構成。18対象セルの学習済み解答制約を再確認し、公式完成例とも18/18一致した。
- 元の「完成色が一意でない」という保留は、保持または学習作用で到達する色が許容集合内という根拠で再検査する。HDSの断定保留、隔離、未被覆、部分重複を無視しない。
- 第1sessionのL4作用16/16、別2sessionの19/19と22/22が、学習外の作用効果照合で一致。後2sessionには対象外操作が挟まる前の14件/2件を含む。対象外のpaletteクリックやkeyboard操作のhidden効果を「ない」と決めない。

作用教師manifestは path/sha256/start/end（after行、両端を含む）の配列。`--policy-teacher-answer-row 94 --action-teacher-manifest /path/to/manifest.json` を前述CLIへ加える。教師区間の選択は原票索引であり実行時routingではない。適用外、無変化、反証を捨てず出力する。

統合結果は `統合攻略候補.json`、全18セルの完成例照合は `統合完成例照合.json`。低位の `推論解答.json` は色一意性に関する元のHOLDを保持するため、統合結果と区別する。すべて実行許可False。liveの作用後観測とfresh成功は今後必要。
