# 公開列図式規則：条件付き解答と未実行作用

## 構成

- `接続/列図式規則.py`：知覚、固定列操作、同一HDS照会、全割当探索、現在盤面からの未実行作用候補
- `道具/列図式教師検証.py`：公開原票のSHA256確認、完成見本/実提出/実作用からの教師取り込み、保持評価、独立推論CLI
- `検証/test_列図式規則.py`：固定文法境界と公開教師を明示供給した統合回帰

runtimeは教師/解答/録画ファイルを読まない。試験用ディレクトリや外部実験moduleへのimportもない。HDS coreと既存APIを改造しない。

## 正本契約

```
候補を構成する(同一HDS, 盤面, 作用可能番号=available_actions, 出所=出所記録)
観測から候補を構成する(同一HDS, 既存観測)
```

正本出力：適用性、対象群、関係群、目標候補群、作用候補群、保留理由群、規則不確実性、解答選択状態、複数整合解、照会記録、出所、実行許可。

実行許可は常にfalse。HDS確定作用の作成、SDK排出、環境stepはしない。ゲーム/level ID、ファイルhash、録画の解答、固定座標列を意味選択の引数にしない。出所ID/観測指紋は由来だけに残す。英語の新設共通APIは作らない。実在するARCのid/data/x/y、available_actions、公開state値は外部境界のみで扱う。

既存の `図式観測.成分群` と `ARC3境界.観測` を再利用する。未採用の運転記録APIへは依存しない。`候補台帳を構成する` は日本語の対象/役割/関係/前提/作用/差分/保留/由来/支持を返し、書込みは呼出側が行う。

## HDSと固定処理の区別

HDSが取得する対応：

- 記号は中空 → 列展開役割（参照/出力）
- 終端条件に応じた列が一致 → 提出が受理された
- 解答作業 → 必要行動ID

固定処理：4画素記号、6画素枠間隔、10画素容器、標識付き起点、同色参照、行順目標列という知覚仮説。出力/参照の操作語彙、完成見本に合う意味候補の外部列挙、再帰解釈、在庫/空欄の全順列探索、作業順序化、座標化。

HDSが再帰解釈器や知覚文法そのものを発明したとは主張しない。内容/作用の78経験を同じHDSに入れ、すべての段に同じinstanceを渡す。作用に反証を入れると内容側もHOLDする現coreの挙動を保持し、別HDSへ分割して回避しない。

## 適用と複数解

- 適用可能：固定知覚仮説に条件付きで合致したこと。環境全体の理解や実行許可ではない
- 構造上不適用：当該固定文法に必要な可視容器/目標行がない。ゲームの解けなさではない
- 未確認：知覚の曖昧さ、盤面/接続契約の不成立など

HDSの規則不確実性と、支持条件を満たす複数整合解は別項目。複数解を人間の1例へ合わせて除外しない。現在の接続は一意な実行対象だけを提案するため、複数整合解では解答集合を保持して作用候補を出さない。他の候補が実環境に受理されるかは未確認。

## 有限終端と反復

有限終端の参照グラフは全出力列で比較する。有限出力[1,2,3]は目標[1,2]に一致しない。

同じ参照先への再入までに出力が増加したことを確認した生産的反復だけ、目標長までの列で比較する。出力増加のない循環はHOLD。循環候補でも目標長までに生産的再入が確認できなければ判定範囲外として記録する。

公開の最終問題の自己参照成功例は、旧固定文法の「循環は一律不成立」を反証した。これはHDS coreの欠陥証明ではない。新しい反復語彙は固定拡張であり、HDSが成功/失敗から取得する受理対応と区別する。

## 再現

`$SOURCE` は許可された公開録画JSONL、`$EVIDENCE` は出力用ディレクトリ。shell変数として事前に設定する。CLIは指定digestを確認する。

```
python -I -B 道具/列図式教師検証.py train \
  --recording "$SOURCE" --sha256 e26ff1df251af042911126a067c08ee25973b01d3389269472eed6859a4383f2 \
  --answer-rows 12 43 59 256 --goal-ranges 1:59 226:256 --action-ranges 1:59 \
  --memory "$EVIDENCE/学習済みHDS.json" --output "$EVIDENCE/教師記録.json"

python -I -B 道具/列図式教師検証.py evaluate \
  --recording "$SOURCE" --sha256 e26ff1df251af042911126a067c08ee25973b01d3389269472eed6859a4383f2 \
  --memory "$EVIDENCE/学習済みHDS.json" --problem-rows 0 12 43 59 78 144 167 225 \
  --answer-rows 12 43 59 78 144 167 225 256 --output "$EVIDENCE/評価.json"

python -I -B 道具/列図式教師検証.py extract-problem \
  --recording "$SOURCE" --sha256 e26ff1df251af042911126a067c08ee25973b01d3389269472eed6859a4383f2 \
  --row 59 --output "$EVIDENCE/問題のみ.json"

python -I -B 道具/列図式教師検証.py infer \
  --memory "$EVIDENCE/学習済みHDS.json" --problem "$EVIDENCE/問題のみ.json" \
  --available-actions 5 6 --output "$EVIDENCE/独立推論.json"

ARC_PUBLIC_TEACHER="$SOURCE" \
ARC_PUBLIC_SHA256=e26ff1df251af042911126a067c08ee25973b01d3389269472eed6859a4383f2 \
PYTHONDONTWRITEBYTECODE=1 python -m unittest discover -s 検証 -p 'test_*.py' -v
```

公開原票の環境変数を指定しない場合、公開教師統合テストはskipする。skipを公開保持評価の合格として数えない。独立inferは学習済みHDS・問題frame・利用可能作用だけを読む。

この接続は戦略/現在状態の選択、core変更、環境への作用発行を含まない。
